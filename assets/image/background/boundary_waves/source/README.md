# 补绘来源

原画：`../../edge.png`（保持原文件）。使用 imagegen 参照编辑，先一次生成 4×2 八形态，再仅将背景改为纯绿幕用于透明抠色。源图保留在此目录。

首轮要求：同一向右波浪依次经历低水脊、陡坡、伸顶、内卷、前翻、触水、摊开、消退；严格参考原画的粉灰、蓝紫、骨白、块面与薄浪缘，固定比例与水面基准，无场景、文字、光晕。第二轮保持所有浪形，仅清除棋盘与背景纹理，换成纯 #00FF00。

生成结果归档：`exec-b70133b3-ffa1-4917-8a43-8c7c91827987.png`。本文件夹中的 PNG 为该结果的原样副本；透明关键形态与派生 Spine 数据由 `tools/boundary_animation/build_waves.py` 可重复生成。
