## 帧耗时

固定负载包含 32 个 Tap、4 个 Hold、16 个 Ghost 点和反复出现的四组裂解。在同一进程中交替关闭／开启全局效果，每阶段跳过前 60 帧，统计后续 360 帧，关闭垂直同步与帧率上限。

| 阶段 | 平均帧耗时 | P95 | 最大值 |
| --- | ---: | ---: | ---: |
| 关闭，第 1 轮 | 4.140 ms | 5.440 ms | 8.203 ms |
| 开启，第 1 轮 | 4.851 ms | 6.002 ms | 9.197 ms |
| 关闭，第 2 轮 | 4.269 ms | 5.392 ms | 9.633 ms |
| 开启，第 2 轮 | 5.056 ms | 6.599 ms | 8.979 ms |

该负载平均增加约 0.7～0.8 ms，P95 增加约 0.6～1.2 ms。采样中首个记录的重复裂解更新耗时为 1.080 / 1.193 ms；这是预热后的第 20 帧触发记录，不代表冷启动 shader 编译耗时。

真实谱面 `../Charts/charts/test/song.json` 从约 32 秒起使用相同输入与时间步进，各采样 1200 帧；开关阶段处于同一进程。

| 全局效果 | 平均帧耗时 | P95 | 最大值 | 表现更新 CPU 平均值 |
| --- | ---: | ---: | ---: | ---: |
| 关闭 | 10.255 ms | 19.695 ms | 40.434 ms | 6.223 ms |
| 开启 | 11.939 ms | 21.532 ms | 42.141 ms | 7.217 ms |

开启后首次白光激活记录位于 32.068 秒，帧间隔为 16.207 ms，该次更新 CPU 为 21.798 ms。两者分别测量帧间隔与本次更新，不能相加，也不等同于 GPU 时间。Ghost 在 32.418、35.776、38.835、38.926、39.451 秒出现；开关两次的候选结果完全一致。

真实谱面关闭特效时也存在约 40 ms 的峰值，因此本轮没有消除全部卡顿。此处为当前硬件和运行负载下的比较，不推断其他设备表现。原始数据保存在 `builds/visual-review/note-effects/density.json` 和 `comparison-0.json`（关闭）、`comparison-1.json`（开启）。
