2026-09-07，Godot 4.7.2，Windows / OpenGL Compatibility，RTX 4060 Laptop。

播放、暂停、返回开头、循环、撤销、重做使用本地 SVG 图标。倍速和吸附明确标注用途；快捷键及循环时间位于悬停提示。专业字段保留可见，按谱面信息、时间与节拍、试听、外观分组；拍号同行编辑，混合音符可明确选择转为单击或长音。

## 检查结果

新版四组测试通过。新增 UI 回归覆盖播放结束、循环键盘与按钮状态、循环回绕、五档倍率、吸附、工作区恢复、混合选区转换与单次撤销、问题面板和点击定位。

实际渲染和容器边界检查覆盖以下组合，未发现工具栏重叠、图标缺字或整体越界：

| 窗口像素尺寸 | 应用缩放 | 逻辑尺寸 |
|---|---|---|
| 1280×720 | 100% | 1280×720 |
| 1440×900 | 100% | 1440×900 |
| 1920×1080 | 100% | 1920×1080 |
| 1280×900 | 125% | 1024×720 |
| 1600×1000 | 125% | 1280×800 |
| 1920×1080 | 150% | 1280×720 |

当前 Windows 系统缩放为 100%。125% 和 150% 通过应用的 `content_scale_factor` 模拟，没有修改系统显示设置，因此未覆盖操作系统缩放切换及跨显示器 DPI 切换。启动时读取系统缩放；API 依据见 [Godot DisplayServer 文档](https://docs.godotengine.org/en/stable/classes/class_displayserver.html#class-displayserver-method-screen-get-scale)。

最小逻辑窗口为 1024×720；125% 时对应 1280×900，150% 时对应 1536×1080。内容不足以同时展示时侧栏滚动，功能不隐藏。

运行 `tests/editor/run_ui_tests.gd` 可复测。渲染模式下截图和布局记录写入 `builds/ui-review/`：`before.png` 是改动前，`1440x900_100.png` 是改动后；这些本地验证产物不入 Git。

独立导出仅更新写谱器开发包，未导出正式游戏。此前记录的音频端到端同步、密集谱面预览性能和其他整体验收限制仍然有效，本次界面调整不代表这些项目已完成。
