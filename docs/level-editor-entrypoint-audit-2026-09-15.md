# 关卡编辑器操作入口复查 · 2026-09-15

## 已推送的初始修复

初始环境修复为 `31ed6b8`。推送期间 editor 出现队友新增关卡与素材，合并保留后以 `3c411e8` 推送 develop、editor，没有覆盖远端历史。

## 后续发现并修复

| 入口 | 问题与修复 |
|---|---|
| 最近工程／查看恢复稿 | 没有选中项目也可确认，造成无操作关窗；现在禁用确认并保留窗口。取消恢复稿会恢复自动恢复计时。首次启动创建恢复目录，避免不存在目录报错。 |
| 打开工程失败 | 读取无效工程前就停止了自动恢复；现在只在成功切换工程时停止旧计时。 |
| 未保存提示 → 不保存 → 打开 | 自定义按钮回调打开新独占窗口时，旧窗口尚未退出；现在先隐藏旧窗口再继续。 |
| 导出完成／另存复制完成 | 文件任务仅 queue_free，下一窗口弹出时仍可能占用模态；任务结束先退出模态状态。 |
| 素材选择器 | 空 default 导致预览空白；非等长图片动画逐帧不准确；循环后逐帧失效；搜索无结果仍播放旧素材。现统一选非空默认动作、按素材帧边界定位、停止并清空无结果预览。字体预览覆盖也随素材切换清除。 |
| 图片拖入时间线失败 | 创建对象失败后仍对原选区添加显示片段，并提示成功；现在依据创建结果取消整个候选，不修改旧对象或历史。 |
| 文件选择与嵌套动画窗口 | 设置 FileDialog 模式会覆盖提前设置的中文标题；标题改为最后设置。来源替换及动作命名窗口保持模态，继续选择文件前退出旧模态。 |
| 属性控件销毁 | 失焦回调可能在控件已退出树后提交旧文本，触发额外历史和恢复计时器错误；销毁阶段不再提交。 |

## 证据与范围

新回归 `tests/editor/run_level_entrypoint_tests.gd` 经根 Viewport 路由按钮点击、弹窗确认和取消；素材检索、素材帧定位及文件任务也检查最终状态。文本框 Ctrl+S 检查实际保存值；退出界面检查没有额外文档历史。初次复现日志 `Levels/output/entrypoints-before.log` 包含 8 项失败及窗口生命周期错误。

修复后的证据：

- `Levels/output/entrypoints-gpu.log`：实际 GPU 窗口的入口操作链。
- `Levels/output/entrypoints-reliability.log`：多选、取消、撤销、依赖与恢复相关回归。
- `Levels/output/entrypoints-environment.log`：初始环境及共用换景选择入口。
- `Levels/output/entrypoints-animation.log`：动画导入窗口与多动作处理。
- `Levels/output/entrypoints-spriteframes.log`：文件拖入、素材栏到预览的完整路径。

检查覆盖关卡工作区的弹窗挂载和主要确认／取消回调、素材选择器、动画导入子窗口、失败拖入及恢复计时。不是对整个编辑器所有功能无缺陷的保证。真实触摸板、中文组合输入、长时间真人制作与交付 EXE 本轮未测；没有构建程序。测试 ZIP、图片和日志均在 Levels/output 内。

之前的问题在于测试绕过用户入口直接修改文档。本轮新增测试保留入口和结果两端：按钮必须能打开窗口，确认必须产生正确结果，取消与失败不能产生隐藏修改。
