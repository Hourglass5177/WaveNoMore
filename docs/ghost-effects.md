# Ghost 眼睛与柔光

2026-09-15，正式游戏与写谱器内嵌预览共用 `SuManifestationOverlay`。

## 素材

`assets/image/note/ghost/closed.png` 与 `open.png` 原样复制自用户提供的 Ghost 文件夹。两张原图均为 607×527 RGBA，背景 alpha 已为零，不重抠、不重绘，避免损失颗粒和透明边缘。眼部锚点统一为 UV `(0.48, 0.35)`，使转换时位置固定。

更新素材后运行 `python tools/generate_note_glow_masks.py assets/image/note/ghost/closed.png assets/image/note/ghost/open.png`，生成各自轮廓的柔光距离遮罩。默认图使用 192 px 长边加 128 px 留边；装配时按原图尺寸计算遮罩映射。替换的闭眼／睁眼图应保持相同画布与锚点。

## 全局时序和外观

`content/presentation/ghost_note_style.tres` 提供共享 Inspector 参数：

| 参数 | 默认值 |
| --- | --- |
| 素材画布宽度 | 112 设计 px |
| 外晕宽度 | 36 设计 px |
| 骨白 | `#E6DDC9` |
| 入场淡入 | 0.12 s |
| 开始睁眼 | 判定前 0.72 s |
| 睁眼过渡 | 0.24 s |
| 闭眼／睁眼光强 | 0.13／0.95 |
| 闭眼／睁眼本体提亮 | 0.08／0.62 |

两张贴图按预乘透明度平滑交叉过渡，避免透明边缘变黑。闭眼时保留暗色纹理与弱骨白柔光；睁眼后本体、轮廓和外晕一起提亮，纹理仍可见。成功时原地短亮、收缩并淡出，失败时关闭柔光并灰化淡出。

`GameplayRuleSet.ghost_preview_extra_sec` 为策划用的额外预告时间，默认 0.45 秒；与普通接近时间相加，默认总计 2.70 秒。固定预测取样与可见时刻相应提前，因此预测的视觉位置可能变化；生成后位置固定，调频评级、伤害和结算时刻不变。该值已同步参数目录、生成工具及策划表。

## 性能与恢复

一个事件的全部 Ghost 合并为一份静态网格和独立材质，多个目标共用 shader 与四张纹理。加载阶段预备 8 个事件视图，超过并发峰值才扩容；结束后回池。时钟推进只提交一个 `phase` 参数，不重建网格，不创建灯光或逐音符视口。

暂停重复同一时刻不更新；Seek 清场后按目标时间重建闭眼、睁眼与结果状态。实例回收清除结果与材质参数。轮廓光通过离线距离场取样，不执行运行时大半径模糊。

## 工程内检查

- `tests/editor/run_ghost_visibility_tests.gd`：图形像素、亮度差、遮挡、暂停、定位、重复结果、Miss 与池复用。
- `tests/unit/domain/run_ghost_prediction_tests.gd`：不同帧间隔的预测和判定、提前量、评分与伤害不变。
- `tests/visual/run_ghost_art_review.gd`：正式背景上的闭眼、过渡、睁眼截图；固定人工 UV 仅用于美术审看，不用于算法验收。

暂停与直接定位像素一致，重复时间推进不重建网格，结果回收后复用原节点。额外预告不进入 Replay 规则哈希，成绩摘要保持一致。已同步工作簿，既有参数当前值保留。

最终专项结果：预测与 Replay 35 项通过，Compatibility 图形与池复用 26 项通过，正式背景三阶段截图已检查。
