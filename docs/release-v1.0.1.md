# 《冥河，冥河！》v1.0.1

本版发布 Windows x86_64 与 Web 两个平台，工程版本为 `1.0.1`，Windows 文件及产品版本为 `1.0.1.0`。

## 本版变化

- 更新调频杆向引导及出现节奏，保留持续推杆控速、回中停止的操作；引导帽面两端各外展 15°。
- Ghost 达到“过”即可击碎，默认允许落后整程行程的 20%；维持按住要求。
- 设置加入手柄状态与震动测试，震动滑条默认显示 50%，对应原强度；上限 100% 对应两倍倍率，最终受电机输出上限限制。
- 完善手柄导航、菜单光标切换和随从选择，支持 Web 画布随窗口缩放。
- 补全第三关 BOSS 死亡白场：缓慢碎裂、裂光增强和爆发后，整幅游戏画面变白，停留约0.5秒后直接显出结算，不再闪回关卡。局部发光强度不影响结算全白。
- Web 顶部加入独立的“全屏游玩”入口，Esc 退出全屏；窗口变化时保持等比显示，完整保留游戏画面。

## 构建

使用 Godot 4.7.2 的 `Windows x86_64 Release`、`Web Release` 预设。先在 `Game/builds` 中导出和验证，再用同名 ZIP 替换项目根目录 `Releases/冥河，冥河！v1.0.1` 中的 Windows、Web 压缩包。发布目录只保存这两个 ZIP，不保留解压包体目录，也不添加“开始游玩.txt”。

策划参数由导出插件读取当前工作簿并封装进包体。构建时暂时移开本地 UI 检查所用的 `override.cfg`，结束后恢复，避免发行包使用测试存档目录。Web 包装与部署方法见 [Web 构建说明](web-build.md)。

近期相关验证：Ghost 与调频、Replay 回归共 850 项通过；设置与手柄界面 94 项通过。真实硬件震感及全部关卡通关不属于此次构建冒烟检查范围。

本次增量验证：第三关白场与结算衔接32项检查通过，包括掉帧、低发光倍率、多尺寸、重试和失败分支；BOSS 动画采样、双实例白光、战斗及 Replay 确定性回归通过。策划参数工作簿只更新白场相关说明，保留全部当前数值。
