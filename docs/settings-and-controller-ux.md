# 设置与手柄交互

更新：2026-10-15。

## 玩家操作

设置包含声音、画面、手柄、校准四类，沿用现有火框、底图、字体、滑轨和焦点效果。肩键切换分类，分类按钮确认后进入内容；上下移动焦点，左右调整滑条。内容跟随焦点滚动，底部可恢复本页默认、保存或取消。

所有设置共用草稿。切分类保留草稿，“恢复本页默认”只重置当前页；保存后应用并写入玩家配置，取消丢弃本次修改。校准归零复用原逻辑。打开操作说明暂时隔离底层焦点，返回后聚焦原入口。

手柄震动强度为0～100%，每步5%，默认50%，0%关闭。50%对应原强度，100%对应两倍强度倍率。`SettingsService.controller_haptics_scale` 存储于 `settings.cfg` 的 `controller` 分类；保存值仍为实际倍率0～2，旧配置的倍率原样保留；缺项默认为1（界面50%）。原生后端会将最终输出限制在设备满幅以内；普通0.35强度可增强至0.7，Perfect与测试短震原本为1，已满幅后不再增强。关卡将场景原倍率与玩家倍率相乘，Tap/Hold基础强度、频率、持续时间和判定不变，重复保存不会重复叠乘。

“测试震动”使用当前草稿强度请求双侧120 Hz、80 ms短震，强度后端按原能力处理频率。拖动滑条不试震；每次点击先清除上一段测试。离开分类、关闭页面、失焦或断开设备均停止测试。设备不可用时禁用测试并说明原因，仍允许保存偏好。测试页复用独立的现有震动管理节点，退出即释放，不创建玩法震动源。

## 鼠标和随从焦点

手柄有效输入隐藏鼠标，鼠标移动或点击恢复。沿用现有手柄轴阈值，避免漂移切换设备。调频鼠标捕获仍优先；退出捕获按最新设备恢复显示。失焦、活动手柄断开时先交还光标，下一次有效操作才重新应用策略。隐藏鼠标不产生残留悬停高亮。

随从的基础/进阶说明、说明容器和滚动条不参与手柄寻焦，鼠标滚动阅读保留。焦点仅落在可操作按钮；切换到未获得随从时跳过禁用项。弹窗关闭后回到原入口，技能描述原文未改动。

调频帽面的15°外展只是显示范围，详细规则见 `planning/06-调频分档与命中反馈.md`。本轮未改变摇杆操作与累积。
