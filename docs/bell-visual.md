# 编钟素材与反馈接入

2026-09-15。正式灵均场景的 `Bell` 使用 `BellVisual`；原贴图、人物骨骼动画和发波规则保留。`StageVisualTheme` 的构图与光强字段由策划表“08 角色移动”装载，详见 `planning/08-角色移动.md`。

## 素材和坐标

- 当前素材为 `assets/image/scene/bell1.png`，挂在缩放 0.32 的人物下，钟自身缩放约 0.2576。人物场景原坐标保持不变，装配时应用构图参数；死侧由世界槽位旋转。
- `Bell` 使用居中 Sprite2D 和独立材质。钟面保留金属颗粒及刻纹，只做轻量阵营色混合；不能与人物染色材质共用实例。
- 正式教程主题的人物明暗为生者明亮、死者暗淡：生者向浅灰 `0.7357967` 混合 26%，死者向黑色混合 35%。本体与消散灰烬共用该主题映射；钟、宠物、背景和音符仍使用自己的色板。
- 替换钟面后运行 `python tools/generate_note_glow_masks.py assets/image/scene/bell1.png`，生成旁边的 `bell1_glow.png`。原素材有多少透明留边都可以，距离场随原尺寸换算；保留生成文件和 Godot 导入文件。
- 柔光由一个带留边的距离场 Sprite 绘制。无需 Light2D、屏幕模糊、粒子或独立视口；每侧装载时准备材质与节点，运行时仅更新变换和光强。

## 反馈与时钟

`GrayboxStagePresentation` 在角色更新后，使用已有 `_attack_last_hit_sec` 驱动钟体。它记录挥槌动画的实际敲击相位，区别于按住后持续发出的载波。钟体不再建立独立敲击历史，也不改变真实声波的发射时间和位置。

浮动按绝对表现时间计算，受力围绕钟顶轻微倾摆后回正，外晕仍保持阵营色，短促高光偏骨白。当前反馈结束快于人物最小敲击间隔，因此保留最近一次接触即可恢复姿态。后续若延长反馈或提高挥槌速率，应一起检查相邻敲击衔接。

详细美术节奏可在 `BellVisual` Inspector 调整：浮动周期 3.6 秒，柔光宽 22 设计 px，倾摆系数 2.4°（衰减曲线作用后的实际峰值更小），动效时长 0.38 秒。策划表只暴露构图、浮动幅度与整体光强。
