## 制作流程与界面

- 新增真实场景：动画导入窗口、素材选择器、属性面板；时间线新增独立编辑栏。窄画布的低频命令进入“更多”，导入表单可滚动。
- 导入涵盖自然数字排序、帧重排、移除、精灵表区域、帧时长、动作列表、默认动作、棋盘预览、逐帧及时间条。读取图片和写入资源按帧让出主线程，可取消；确认前不产生工程资源。
- 对象素材选择按类型过滤；替换与重新导入保留 ID 和编排，清引用与删除分开，失效动作定位到片段。未使用资源先列清单再移到 `.unused/`，保留文档、撤销、恢复稿引用。
- 显示背景层名称与最终位置，支持继承及明确停止继承。对齐与等距分布复用变换命令，父子多选只改根对象。
- 共同轨和当前难度轨的整段调整、比例缩放、插值保持、选中键限定、锁定轨拒绝部分调整均有专项检查。
- 1024×720、1280×720、1920×1080、3440×1440，及 2560×1440 下 100%／150%／200% 界面倍率完成事件和 GPU 检查；另覆盖最大化、还原。画布变换的坐标往返一致。导入窗口标题与确认按钮在小窗口内可见，表单提供滚动。
- Space 专项：GPU 进程窗口取得焦点后记录 `window_has_focus=true, background=false`，按钮焦点下经 Viewport 路由能够播放。文本框空格不播放由布局回归覆盖。此结论有前台条件，不把隐藏窗口的输入结果当成真实操作。

## 未实测与交付边界

真实触摸板硬件、中文输入法组合输入、跨屏 DPI 切换及实际交付 EXE 未实测。100%／150%／200% 是编辑器界面倍率检查，不等同于操作系统 DPI 检查。GPU 操作为程序注入 Viewport 事件并检查渲染结果，没有把它写成真人完成全部制作流程。后续交付新 EXE 后，仍需用实际设备重复导入、拖放、字段编辑、取消、保存恢复及试玩流程。

旧审计探针保留为历史复现入口，它只打印值，退出码 0 不能用来替代本记录中的通过条件。早期失败日志保留在 output，最终结论使用 `final-animation.log`、`ui-final-gpu.log`、`layout-headless.log`、`source-trial.log` 及各专项日志。
