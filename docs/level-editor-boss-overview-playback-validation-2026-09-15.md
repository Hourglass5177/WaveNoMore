# BOSS 总览与骨骼播放验收（2026-09-15）

## 修复结果

- 新增独立只读 BOSS 参考轨与无需选对象的总览，支持 Hold 范围、当前难度统计、绑定状态筛选、搜索、定位、来源绑定查看和明确加入绑定。
- 原共享动画驱动禁用了素材根节点的处理。手动采样能够改变骨骼姿态与播放时间，但继承禁用状态的 Spine 原生节点不能刷新绘制网格。现在 Spine 节点显式使用可暂停处理模式，动画时间仍由手动采样控制，素材根节点仍保持禁用。
- 导入窗口播放按钮同步显示播放／暂停状态。

## 工程内验证

引擎：Godot 4.7.2；实际 GPU：NVIDIA RTX 4060 Laptop，Compatibility 渲染。测试产物位于 `Levels/output`，不纳入源码提交。

| 检查 | 结果与证据 |
| --- | --- |
| 原故障复现 | `spine-playback-before.log`：时间、骨骼变换变化，但播放前后像素相同，画面断言失败。不能只凭时间推进判定通过。 |
| 骨骼导入连续播放 | `spine-playback-after.log`：通过视口鼠标事件点击播放，时间、姿态及像素均变化；暂停后像素不变。 |
| 独立演出播放器定位 | 同上：导入素材在 LevelShowPlayer 中定位 0 与 0.5 秒画面不同，回到 0 秒恢复相同画面。 |
| 总览交互 | `boss-overview-tests.log`：无对象选区可浏览、筛选、定位；没有文档／历史修改。实际点击轨道标记打开对应条目。 |
| 绑定与撤销 | 同上：明确加入已有绑定只产生一次历史，撤销移除新增关联；切换难度不混入另一难度记录。 |
| Hold 与失效关联 | 同上：Hold 时间范围和提示正确；缺失音符列为失效，不生成虚假时间。 |
| 相关可靠性回归 | `boss-overview-reliability.log`：既有 level reliability 测试通过。 |
| 实际画面 | `boss-overview/timeline.png`、`boss-overview/overview.png`：检查独立参考行、颜色图例、状态统计、列表和操作入口。 |

测试脚本为 `tests/editor/run_boss_overview_tests.gd`、`tests/editor/run_level_spine_import_tests.gd` 与既有可靠性测试。新增列表使用单行分隔显示，完整多行信息保留在悬停和详情中。
