## 可重复验证

在 Game 目录运行 `tests/editor/run.ps1 -GodotExe <引擎路径>`，每个套件独立进程，默认 60 秒超时，同时检查完成标记、退出码和错误日志。

- `run_studio_tests.gd`：JSON 时间/往返、未知内容、结构错误、草稿冲突；实际鼠标事件拖画、选区移动、头尾把手、Shift 框选、一次撤销；组合复制；保存重开、三种音频波形、旧谱归档、另存为、ZIP 与游戏读取；Hold 状态/波前恢复与取消过期请求。
- `run_input_tests.gd`：通过 Godot 输入分发验证空格、F/J、文本焦点；未按回车的 135.125 BPM 在点击保存时提交，且一次撤销。
- `run_workspace_smoke.gd`：实例化实际工作区、打开示例、定位 4.2 秒。带渲染运行时另存截图。
- 对 2.02、2.3、3.05、4.2、5.3、6.2 秒，比较从头推进与直接定位的活动音符 ID、接触、时刻、Hold 进度、位置和颜色。当前通过；这不等于已验证所有主题中的每一种特效。

领域测试已恢复可编译，保留 7 项基线失败：核心 131 项中 1 项（暂停重按 Hold，预期 0 实际 3）；调频 101 项中 6 项（提前完成与末段回退、最佳等级/进入标记/误差时间）。共享索引及预览改动后重复执行，失败集合未扩大。没有将全工程测试描述为全绿，也没有恢复已废弃的 InputRouter。

## 音频证据与限制

五档 .5/.75/1/1.25/1.5 倍，独立音乐总线使用逆向 PitchShift（FFT 1024、oversampling 4）。真实 WASAPI 驱动下录制总线，440 Hz 稳态频率五档均测得 440 Hz；数据见 [音频测量](chart-editor-audio-measurement.json)。

1 倍首音额外延迟约 1.42 ms，其余档约 12.04–12.79 ms；差值约 11 ms。Transport 加入 512 / mix_rate 的处理延迟估计，同时独立保存设备试听补偿。该补偿尚需与实际输出、提示音和屏幕反馈联合复测。

总线录音不证明扬声器端到端延迟；纯音频率不证明音乐瞬态质量。当前提示音仍通过运行帧触发；循环尾音、变速切换后的残留缓冲及说明书要求的 ≤10 ms 同步尚未完成验收。不能把五档“可播放”写成保音高方案全面通过，也不以随速率变调降级替代。

五分钟 1 倍实测：WASAPI、48000 Hz 总线录音，30 个脉冲的首尾理论间隔 290 秒，实测 290.000958 秒（误差 0.958 ms）；Transport 相对墙钟的前后区间中位数变化 0.698 ms。该单倍率测量通过 5 ms 漂移标准，其他倍率及真实输出仍未覆盖。原始摘要见 [长期音频测量](chart-editor-audio-longterm.json)，复测使用 `measure_audio_longterm.gd` 与 `analyze_longterm_audio.py`；长测不要用按帧数提前退出的 `--quit-after`。

## 交付与协作边界

- 公共 JSON/领域/预览接入口与工具 UI 分开提交；共同接口见 [接口说明](chart-editor-interfaces.md)。
- `builds/chart-studio/` 为本地生成物，不入 Git。发布预设仅导出写谱器，正式游戏没有另行导出。
- 当前 EXE 已在工程目录之外以嵌入 PCK 启动，日志无脚本错误；实际渲染工作区截图检查通过（RTX 4060 Laptop、OpenGL Compatibility）。这两项不替代另一台电脑的完整操作验收。
- 旧资源导入的新工程保留 `legacy/`；可玩包不执行这些内容。编辑稿可保存不受支持的音符，但不能以其为可玩导出。
- 旧编辑器暂留，原因是计划明确要求“新版通过验收后删除”。不新增旧工具功能，不将双实现作为长期安排。
- 后续优先完成音频与密集谱验收，再进行全流程谱师试用和旧工具清理；当前包标注为开发版。
