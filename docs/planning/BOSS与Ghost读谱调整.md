# BOSS 与 Ghost 读谱调整

BOSS 音符默认在普通路线 5% 处衔接，保留 95% 的正常接近路程；按路程提前出手，判定时间不变。`boss/route_join_ratio` 可在 0～0.2 范围调整。BOSS 挂在深度零玩法层之前，其骨骼内部层级不会遮盖音符。

Ghost 按关联调频当前单程截至该时刻的行程完成度判断：达到 Good 即可击破，双方均需满足；仍需保持对应输入。端点与已结束段沿用实际评价。漏击伤害从 6 降至 3，不调整 Tap、Hold。成功时骨白眼睛裂片向外爆开，持续约 0.65 秒，随歌曲时钟暂停及清理。

## 结算口径修复

Ghost 不追加基础计分单位，但漏击会中断 Combo 和 FC/AP。Good 击破允许 FC，不满足 AP。结算单独展示 Ghost 击破／漏击数量，命中率与臻率的分母包含全关卡预设 Ghost 数量，提前失败不缩小分母。现有奖励和关卡解锁记录不追溯删除。加载页正常状态固定显示“路漫漫其修远兮，吾将上下而求索”，仅错误状态显示失败原因。
