# 角色移动

2026-09-14。灵均使用小步前行，左右各一步为一轮。准备阶段静息；正式进行后按主地景实际滚动启停，攻击收招后返回相应动作。暂停冻结，不触发收步；移动受击沿用局部叠加，步态时间继续推进。

参数表“08 角色移动”在重新装载关卡时应用到视觉主题副本。修改 B 列当前值，保存后重新进入关卡或重建编辑器预览。参数不参与判定、发波或 Replay 规则摘要。

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| `walk_period_sec` | 1.6 秒 | 一轮两步；不随 BPM 或发波频率改变 |
| `walk_mix_sec` | 0.18 秒 | 移动与静息的切换混合；攻击收招仍为 0.15 秒 |
| `walk_stop_speed_px_sec` | 0.5 设计 px/s | 主地景实际速度低于此值时静息 |
| `life_movement_layer_key` | `50/default` | 生侧主地景连续性标识 |
| `death_movement_layer_key` | `50/sublayer_55` | 死侧主地景连续性标识 |

当前五份背景的参考层均为深度 50 的主要地景，不读取粒子、飘雾或分界浪头。字段使用 `continuity_id`，未填写时使用现有的“深度/子层 ID”；资源名和显示名不参与匹配。更换背景后如果更换了参考层身份，应同步这两个字段。留空或找不到参考层时静息。

环境编排按主地景的实际运动区间取速度，包含稳定镜头平移；震屏、手持晃动和淡入淡出不触发步态。切换过程中旧地景尚未离场时继续读取其运动。旧关卡使用子层速度与主题镜头速度。两侧独立启停，循环相位以同一歌曲时间计算。

动作造型在派生素材生成器中制作：脚部行程约 24 px、抬脚约 3.5 px、骨盆起伏约 2.4 px；这是当前 0.405 角色缩放下的设计画布尺度，不随表格步频改变。移动裙摆的横向跟随收小 15%，保持裙腰和步幅；这是素材修形，不增加表格参数。裙摆由腿部 IK 解算姿态烘焙，运行时不新增布料模拟。

源代码：`src/content/resources/stage_visual_theme.gd`、`src/presentation/adapters/actor_locomotion.gd`。新字段使用现有策划表同步脚本保留已调整的当前值，参考层支持文本输入。
