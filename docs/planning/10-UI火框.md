# UI 火框

用于正式选关卡片、设置弹窗、暂停面板及素材审看。修改工作簿“10 UI 火框”黄色当前值，重新打开对应界面生效；发行程序使用现有构建参数快照。

| 参数 | 默认 | 范围 | 步长 | 含义 |
| --- | ---: | --- | ---: | --- |
| 火势高度 `flame_height` | 48 设计 px | 24～72 | 2 | 决定主要火舌长度，环带透明边距随之更新。 |
| 燃烧速度 `speed` | 90 设计 px/s | 0～180 | 5 | 根部保持固定，控制焰身上窜、卷动与尖端消退的速度；0冻结。 |
| 柔晕强度 `glow_strength` | 1 | 0～2 | 0.1 | 调节局部柔晕及八个附属火尖；0保留主要火焰。 |

正式弹窗按底图可见边缘确定框尺寸，使用红焰；卡片的 `flame_palette` 可选择无／红焰／蓝焰，当前目录使用蓝焰，位置与尺寸跟随背景。独立组件仍可在 Inspector 设置尺寸、预设和种子。红蓝使用同一运动规律，随机种子避免多个实例同步。参数属于表现，不进入玩法规则或 Replay 摘要。
