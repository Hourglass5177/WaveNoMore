# 调频分档与命中反馈

2026-09-14。最新规则优先于旧交接文档的 Perfect／Miss 二档描述。

## 调频评分

每程规定尾点时刻采样当前位置。完成度为 `1 − abs(当前位置 − 本程终点)`，位置按单程归一化，折返方向自动反转。提前完成可以保持到终点；不增加尾点后的晚到窗口，不按整程覆盖率计分。

| 等级 | 最低完成度默认值 | 策划字段 |
| --- | ---: | --- |
| Perfect | 97% | `tuning_perfect_completion` |
| Good | 90% | `tuning_good_completion` |
| Pass | 80% | `tuning_pass_completion` |
| Miss | 低于 Pass，或终点未按住对应钟 | — |

三个阈值位于策划表“03 调频”，均包含边界；使用现有输入量化，不额外扩大判定范围。多程或组合取最差分项，按现有基础分 1000／700／400／0 计分。Tuning 所有等级均不扣血。

2026-10-15：Ghost 位于节点／尾点时，关联 Tuning 达到 Pass（过）即可击碎、不扣血；只有 Miss 漏击。区间内部按整段行程容错：评价完成度 = 1 − max(当前目标进度 − 实际进度, 0)，击碎底线使用同一 Pass 阈值。默认允许落后整段20%，包含边界，提前有效；仍须保持双 Hold 和所属钟。双侧关联取较差一侧。Ghost 预测坐标不参与碰撞评分。Pass击破保留FC资格，不计为Perfect或AP，也不追加基础分。

## 摇杆推进与引导

2026-10-12 以主策划最新纠正为准：**摇杆控制速度，随时间累积进度，不是绝对角度对应位置。** 恢复 Git `10bee67` 的速度基线与不超过 1/240 秒的积分子步。完整恢复原版切线投影和往返程换算，死区外推量线性控制速度。持续推住会继续走，回中停止并保留进度，反向推会逐步退回。鼠标仍使用位移。

速度基线为 `单程弧长 / max(单程秒数 − 每程完成容错秒数, 0.001)`；每程完成容错恢复原默认 500 ms。新速度仅乘 **1.02**，也就是比原版快 **2%**。停用此前错误引入的角度助推，撤销前轮 1.15 的大幅提速。小于或等于容错时长的短程仍沿用原版快速完成行为，本次未另改短程难度。

策划表“03 调频”恢复 `tuning_speed_tolerance_ms` 和 `tuning_progress_speed_multiplier` 两个原有行；仅将推进倍率当前值按本次要求改为 1.02，其他已调整值保留。内部兼容字段 `tuning_stick_max_speed_px_sec` 沿用原版的 600；当前每程速度由上述公式决定，此字段仅在为零时停用速度推进。

引导显示谱面位置相对圆心的径向，起点左上、中点正上、终点右上；折返沿同一上弧返回，死侧中心对称。两端各外展15°仅影响帽面显示，不能改变输入方向、往返换算或累积计算。实际输入保留原版切线速度积分，绝不读取帽面方向。引导按谱面时钟运行，不因玩家提前填满而回中。整条结束后，保持最后一程的最终杆向直至淡出；换程从上一程终点方向沿原弧返回。预告静态，暂停冻结。帽面、缩圈、透明度和批次编号沿用当前表现。

Ghost 使用速度积分得到的真实进度。中途允许落后整程20%（评价完成度为 `1 − max(目标已走距离 − 实际已走距离, 0)`），节点／尾点读取已结算的完成度，达到 Pass 80% 即可击碎。提前有效，双侧取较差一侧；仍需双 Hold 与所属钟保持。停杆不冻结目标进度，视觉磁吸、帽面方向和预测坐标不参与判定。
