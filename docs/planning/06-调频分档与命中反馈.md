# 调频分档与命中反馈

2026-09-14。最新规则优先于旧交接文档的 Perfect／Miss 二档描述。

## 调频评分

每程规定尾点时刻采样当前位置。完成度为 `1 − abs(当前位置 − 本程终点)`，位置按单程归一化，折返方向自动反转。提前完成可以保持到终点；不增加尾点后的晚到窗口，不按整程覆盖率计分。

| 等级 | 最低完成度默认值 | 策划字段 |
| --- | ---: | --- |
| Perfect | 97% | `tuning_perfect_completion` |
| Good | 90% | `tuning_good_completion` |
| Pass | 80% | `tuning_pass_completion` |
| Miss | 低于 Pass，或终点未按住对应钟 | — |

三个阈值位于策划表“03 调频”，均包含边界；使用现有输入量化，不额外扩大判定范围。多程或组合取最差分项，按现有基础分 1000／700／400／0 计分。Tuning 所有等级均不扣血。

Ghost 位于节点／尾点时，关联 Tuning 的 Perfect、Good、Pass 均视为完成；Miss 才会造成 Ghost 漏击伤害。位于区间内部时保持现有实时行程检查。Ghost 预测坐标不参与碰撞评分。

## 表现

- 普通敲击波、持续载波及旧疾振波包统一读取 `NoteEffectStyle.life_halo`／`death_halo`，默认生 `#517587`、死 `#AD4638`；移除旧死波补蓝。背景、中央判定框形变与骨白相纹不改色。
- Hold 头命中后的累积环：右生逆时针，左死顺时针，亮线和柔光方向一致。接近阶段不变；回收后重置方向。
- 中央短亮印记与头判等级在正确按下时立即触发。读取正式发波记录中已接受的音符身份、头判等级和精确输入时刻；Tap 与 Hold 共用。续按、空按及之后的物理接触不重播。Miss 保留原反馈。
- 声波传播、音符裂解接触时间和后续判定规则不提前；短反馈按现有视觉时钟计算，暂停冻结，预览重演重建。

## 使用策划表

修改黄色 B 列并保存，返回选关重新进入，或在写谱器重新打开谱面。已开始的一局、暂停恢复、Seek 不实时更换规则。写谱器一键试玩自动传递同一表格路径；独立启动游戏使用其 EXE 同级 `planning/策划参数.xlsx`。无需运行同步脚本，脚本仅在开发者增加字段时使用。
