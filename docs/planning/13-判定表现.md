# 判定等级图

关内“臻、良、过、失”沿用原图片笔画，扣除各自透明留白后等高显示。默认实体高度 160 设计像素，保留长宽比例；原有出现、弹回和淡出时序不变。

| 等级 | 颜色 | 色值 |
| --- | --- | --- |
| 臻 | 橙黄色 | `#ffba48` |
| 良 | 绿色 | `#77d68d` |
| 过 | 灰蓝色 | `#8fa7bd` |
| 失 | 灰色 | `#a5a5a5` |

工作簿“13 判定表现”提供四色、不透明度、字形基准高度、柔光半径和强度。颜色填 `#RRGGBB`。默认不透明度 70%，柔光半径 12 设计像素、强度 1.5。字形基准高度 640 乘现有资源 `scale=0.25`，得到 160 像素实际高度。位置沿用资源的 `offset`。

原图低透明度的异色光晕由材质剔除；原笔画与新增柔光共用等级颜色，最后统一乘 70% 不透明度，淡出时一起消失。透明边距自动预留；不使用全屏辉光、额外 Viewport 或逐命中读取图片。

保存表格后下次装载关卡生效，正式游戏与写谱预览共用 `StageHud`；每个 HUD 使用独立材质与配置副本，不改变计分、判定或 Replay。

验证：`tools/ui/run_ui_review.ps1 -Suites judgment-art,pet-rules`。正式 Compatibility 渲染截图在 `builds/judgment-review`，检查等高、最终像素透明度、实例独立及重复判定后的淡出。
