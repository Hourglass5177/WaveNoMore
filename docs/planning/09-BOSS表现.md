# BOSS 表现

仅用于 `tools/boss_animation/review.tscn` 素材审看，尚未接入正式 BOSS 事件。修改工作簿后重新打开场景。

| 字段 | 默认 | 范围 | 步长 | 用途 |
| --- | ---: | --- | ---: | --- |
| `boss/glow_strength` | 1.0 | 0～2 | 0.1 | 光波、喷火、眼光、羊头裂光与白场亮度。觉醒时两侧眼睛变白，额眼保留虹膜。手部不整体提亮。 |
| `boss/effect_scale` | 1.0 | 0.5～1.5 | 0.1 | 光波、火焰、羊头光束及骨片扩散范围，发射根部保持绑定。 |
| `boss/fragment_multiplier` | 1.0 | 0.25～2 | 0.25 | 实例创建时决定附属碎屑数量。羊头六片额眼表层与34块骨片固定。 |

动作时序和骨骼编排保存在派生素材生成器中。三个倍率均不写入玩法规则或 Replay 哈希。

羊头一阶段使用3秒 `phase_break`，结束后进入真眼形态常态。二阶段死亡7秒；白场在4.80～5.15秒渐满，5.15～5.65秒保持，5.65～6.65秒退去。双侧白场取最大强度，审看控件位于白场上方。默认倍率1时达到纯白。
