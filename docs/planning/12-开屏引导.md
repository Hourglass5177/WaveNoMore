# 开屏引导

工作簿“12 开屏引导”在正式游戏启动时读取一次，不参与玩法规则或 Replay 内容。工程内保存后重启游戏生效；发行程序沿用构建时封装的参数快照。

| 参数 | 默认 | 允许范围 | 含义 |
| --- | ---: | --- | --- |
| 页面淡入 `fade_in_sec` | 0.6 秒 | 0.1～2 秒 | MEMO、耳机、操作说明共用。 |
| MEMO 停留 `hold_sec` | 1.2 秒 | 0.1～8 秒 | 图样完整显现之后的停留时间。 |
| 页面淡出 `fade_out_sec` | 0.6 秒 | 0.1～2 秒 | 三页共用；最后另有 0.3 秒黑场过渡。 |
| 耳机提示停留 `headphones_hold_sec` | 2.4 秒 | 0.1～10 秒 | 完整显现之后的阅读时间。 |

统一微调步长 0.1 秒。操作说明没有自动关闭倒计时，由玩家确认继续。返回标题页不重复播放，设置中的“操作说明”可随时查看。现有开屏 Inspector 字段保留；表格中同名字段优先。

标题页首次“点击任意处”之后播放本地 `assets/pv.ogv`。播放结束或跳过后进入选关第一关；同一次启动返回标题不重播。以上四项参数只控制开屏引导，PV 时长来自视频本身，不另设策划倒计时。接线与按键说明见 [开场 PV](../launch-guides.md#开场-pv)。
