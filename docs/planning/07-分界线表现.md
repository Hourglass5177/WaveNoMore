# 分界线表现参数

工作簿页签：**07 分界线表现**。修改黄色 B 列当前值，保存并重新装载关卡或预览。对象名 `boundary`，不进入 GameplayRuleSet 或 Replay 哈希。

| 字段 | 默认 | 单位 | 含义 |
| --- | ---: | --- | --- |
| `enabled` | 1 | 开关 | 关闭显示原始静态分界线 |
| `bar_interval` | 1 | 小节 | 大浪拍落间隔；每道浪跨两小节 |
| `wave_height_px` | 165 | 设计 px | 伸顶时的浪高 |
| `advance_px` | 190 | 设计 px | 起势到拍落的浪身前进距离 |
| `curl_travel_px` | 90 | 设计 px | 卷顶横向翻送尺度 |
| `foam_strength` | 0.9 | 比例 | 拍落后的白沫不透明度 |
| `flow_enabled` | 1 | 开关 | 基底水流；关闭后保留厚底带及活动浪头 |
| `flow_speed_px_sec` | 60 | 设计 px/s | 基底原纹基准流速，局部随宽窄调整 |
| `flow_strength` | 0.80 | 比例 | 原纹流动颜色的混合强度 |
| `streak_strength` | 0.24 | 比例 | 原画细水线的峰值混合强度；0 只关闭细纹 |

尺寸以 1920×1080 为基准。小浪每拍产生、三拍消退，前进约 140 px；白沫触水后继续前进约 120 px。小节长度来自谱面拍号，变速来自 TempoMap。每侧最多两道中央浪、三道小浪。

基底水流使用歌曲秒数，不随 BPM 加速。两组相差半周期的短行程每 2 秒衔接，默认原纹偏移约 ±60 px；细纹速度约为原纹的 1.3 倍。外缘 6 px 固定，向内再用 5 px 渐入；中央约 55 px 内不增加基底颜色流动，随后在 90 px 范围内渐入。这一内部颜色权重不裁切透明度，活动浪花也不再使用圆形挖空。总动画关闭时仍恢复完整原静态图。

旧 `period_sec`、`stream_amplitude_px`、`curl_amplitude_px`、`beat_enabled`、`beat_amplitude_px` 已停用，工作簿保留旧当前值的灰色记录行，不再装入运行配置。`enabled` 的人工当前值继续保留。重复同步不会覆盖退休记录，也不重置其他策划值。

资源：`content/presentation/boundary_motion_style.tres`；字段：`src/content/resources/boundary_motion_style.gd`。素材和接入方法见 [波浪分界线](../boundary-motion.md)。
