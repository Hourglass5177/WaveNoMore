# 冥河写谱器 v0.1.5

2026-09-14 · Windows x86_64

- 优化长谱预览加载与定位：只恢复仍可见音符的身体运动，角色按动作边界推进，复用编译结果与关卡实例。
- 持续 Hold 增加内存运动缓存，反复定位时复用；不写入谱面文件。
- 第二关后段定位由约 33 秒降至约 3 秒，缓存后约 2 秒，实际耗时随电脑负载变化。非常密集的谱面仍可能等待较久，全部性能目标尚未达到。
- 保留加载蒙版、最新定位请求、完整玩法判定及现有音频行为。详情见 [性能记录](docs/chart-editor-preview-performance-2026-09-14.md)。
- 修复旧开发参数表导致“第二关”无法预览的问题。参数在构建时自动封装进程序；谱师无需维护 Excel，目录中遗留的旧表不会影响预览。
- 配套游戏同步更新，一键试玩自动使用写谱器的封装参数。

完整解压 ZIP 后运行 `minghe-chart-studio.exe`。使用方法见 [写谱器使用说明](写谱器使用说明.md)，玩法见 [音符与玩法介绍](音符与玩法介绍.md)。

写谱器与配套游戏文件版本均为 **0.1.5.0**。配套游戏位于 `game/minghe.exe`，供“在游戏中试玩”调用。识别器、模型和许可原样附带，无需另装 Python 或联网下载模型。

示例位于 `charts/示例工程` 和 `charts/Tuning示例工程`。用户自己的第二关、教程2、test 和其他谱面不进入发行包，也不被更新程序覆盖。
