# 冥河写谱器 v0.1.3

2026-09-10 · Windows x86_64

- Tap 命中时立即隐藏外圈与双押白光，播放短促命中反馈；暗淡本体继续移动，声波接触后原地消散。
- 单条 Tuning 可设置独立半径，支持自动模式、1 px 微调、撤销、复制、保存、恢复和导出。生死两侧可分别编排，调频要求不变。
- 修正数值箭头微调的即时提交，以及预览定位后的 Tap 回收状态。
- 写谱器和 `game/minghe.exe` 同步重建，更新操作说明及效果图。

解压整个目录后运行 `minghe-chart-studio.exe`。点击“在游戏中试玩”启动配套游戏。

沿用 v0.1.2 的节拍识别器、离线模型、依赖许可、test 示例、Tuning 示例和目录结构。旧谱继续使用自动半径，无需转换。相纹亮度仍在游戏设置中调节，范围 35%～100%，默认 85%。

操作方法见 [写谱器使用说明](写谱器使用说明.md)，新增效果见 [Tap 与 Tuning 表现说明](docs/tap-feedback-tuning-radius.md)。
