# 冥河写谱器 v0.1.4

2026-09-11 · Windows x86_64

- 预览区新增场景选择与“使用场景演出”开关。场景按当前难度保存，支持撤销、重做、复制难度和恢复稿；演出默认关闭。
- 写谱预览与配套游戏共用 Godot 主题、视差背景、角色和素材装配，包含最新 s08 美术及灵均攻击动画。
- 工程内运行写谱器时可刷新 Godot 已保存、已导入的场景资源。发布版使用包内资源，更新素材需要重建写谱器和配套游戏。
- 修正自制谱引用 s08 时的角色层级，以及预览暂停、回拖后的灵均动画状态。切换场景会暂停播放并保留当前位置。
- 保留 Tap 命中反馈、Tuning 自定义半径及此前的预览性能优化。只有旧主题字段的谱面保持原表现，明确选择场景后再升级绑定。

解压整个目录，运行 `minghe-chart-studio.exe`；“在游戏中试玩”使用同包的 `game/minghe.exe`。两个 EXE 的文件版本均为 0.1.4.0，需一起更新。

沿用已发布的节拍识别器、离线模型、依赖许可及示例，不需要重新下载模型。用户工程不作为发布包来源。

操作方法见 [写谱器使用说明](写谱器使用说明.md)，工程接入方式见 [场景接入说明](docs/chart-studio-scenes.md)。
