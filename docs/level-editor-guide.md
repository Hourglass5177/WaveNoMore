# 冥河关卡编辑器使用说明

适用：2026-09-14 源码开发版，Windows x86_64，Godot 4.7.2。

## 工作目录

仓库外的 `Levels/` 存放关卡编辑器运行文件；工程源码仍在 `Game/`。直接运行 `Levels/minghe-level-studio.exe`，或用 `打开示例.cmd` 打开 `example/level.json`。自建工程放在 `Levels/projects/`，验证输出放在 `Levels/output/`，已有发行包放在 `Levels/releases/`。

本轮可靠性与制作流程改进已进入源码，尚未重新构建 EXE。2026-09-13 的 0.1.4.0 交付程序不包含本轮改动；该次构建记录仍在 Levels/output/editor-build-20260913/。

## 打开交付包

完整解压交付 ZIP，再运行 `minghe-level-studio.exe`。两个同目录 DLL 和 `game` 文件夹需要一同保留。工具与配套游戏均为独立程序，使用者无需安装 Godot。

点击「打开」，选择 `example/level.json`，即可查看渡口演出示例。建议先「另存为」到自己的工作目录。点击「在游戏中试玩」会自动使用 `game/minghe.exe`；也可在「工程工具 → 选择配套游戏」指定其他位置。

`渡口演出.level.zip` 是可直接交给配套游戏的关卡包。在游戏的「本地谱面与关卡」目录导入它，选择难度后游玩。正式目录游玩记录各难度成绩，并执行关卡配置的奖励与解锁；从编辑器启动的试玩不写正式成绩。

## 从歌曲制作一关

1. 新建工程并保存到空目录。
2. 点击「导入歌曲」，选择写谱器工程的 `song.json`。工具复制音乐和全部难度谱面，并记住来源位置。
3. 点击「导入素材包」，选择美术交付的 `.assetpack.json`；对应 `.pck` 须在其旁边。普通图片、声音、字体直接用「导入素材」。
4. 双击素材或拖入中央预览；也可切换左侧「对象」，使用「添加对象」。调整位置、层级和动作。
5. 在「曲前 / 歌曲 / 曲后」分别编排。点击右侧固定的「关卡设置」，填写片头、片尾长度。
6. 切换歌曲难度，为各难度的 BOSS 音符建立绑定；演出默认共用。
7. 预览并试玩，处理底部问题列表，再「导出关卡包」。草稿允许保存，导出和正式试玩要求歌曲、素材及关联完整。

原谱面在此只读。音符、拍点、调频路径和 BOSS 标记继续在写谱器中修改。回到关卡设置点击「刷新关联谱面」，主动更新已保存副本；绑定继续使用稳定音符 ID。被删除或取消 BOSS 标记的关联会显示具体问题，需要重新选择，不会自动猜配。

## 环境场景的顺序编排

1. 点击时间线工具栏的「环境场景」，在右侧「选择初始环境」。这只改变背景，角色、编钟、音符和 HUD 继续沿用关卡配置。
2. 左侧素材库选择「环境场景」分类，将后续背景拖到时间线；也可用「添加换景」放到游标处。内置背景与素材包背景在同一列表中。
3. 标记表示请求时间。各层等到下一处尚未入画的循环接缝再开始进入，旧内容完全退出后采用新速度。密集请求按顺序排队，不跳过中间场景。
4. 展开环境轨道，查看各层的等待、进入和完成范围。点击范围选中来源请求；只有请求标记可以拖动。重叠标记显示数量，右键选择具体请求。
5. 右侧可精确设置时间、难度范围及效果。「无」直接拼接；「淡化」只混合滚动接缝附近，默认宽度 128 设计像素。固定装饰从请求时刻更换或交叉淡化，默认 0.5 秒。单层可覆盖效果，取消「单独设置本层效果」恢复继承。
6. 使用「预览这次衔接」，从最早入画前 1 秒播放到最后完成后 1 秒，范围限制在关卡内。可显示接缝、单独看一层、逐帧检查；退出恢复此前区段、播放位置、循环和浏览视图。歌曲结束前未完成的请求会显示提示，不自动延长歌曲或片尾。

Shift 点击增减选择，空白拖动框选；点击多选成员保留选区。拖动超过 6 个逻辑像素开始候选编辑，Alt 临时关闭吸附，松手提交一次撤销。Esc、失焦或打开菜单取消拖动。多选属性中的「整体平移」保持请求间距；复制、粘贴和删除作用于换景选区。浏览与界面倍率不会改变实际衔接时间。

### 美术制作循环背景

在 Godot 背景编辑器中选择子层，使用「循环与衔接」设置循环起点、终点、方向。画布上的两条线可拖动，字段支持精确输入及恢复默认。默认范围来自素材缩放后的组合外框；循环范围只安排接缝，不改变素材原有平铺尺寸。

同一视觉层在不同背景中使用相同「对应层标识」。复制背景保留此标识；旧资源留空时按「深度＋子层 ID」对应。名称仅供显示，深度仍决定视差和遮挡。下一场景缺少某层时滚出至透明，新增层从进入边缘滚入；完全相同的层继续原来的内容和动画。

「本场景循环预览」「接下一个场景预览」使用正式拼接器；后者在 1 秒处请求换景。可切换淡化、单层查看、辅助线、暂停和逐帧；退出恢复编辑视图。预览目标与这些辅助选项不保存进背景资源。美术负责循环尾部与下一场景头部的视觉接缝，无需填写兼容关系。

将背景放入 `VisualAssetEntry.background`，填写 ID、名称和缩略图，再通过原素材包导出入口生成 PCK。关卡制作端按名称选择，无需手工对应层。新增资源接口与动态材质要求见 [数据与素材接口](level-editor-interfaces.md)。

## 工作区与对象

左侧是素材库和对象树，中央是正式玩法预览，右侧是属性，底部是时间线。拖动面板分隔线调整空间；「视图」可折叠左右面板、底部时间线，或恢复布局。「专注预览 / 恢复」保留进入前的布局。

「视图 → 界面倍率」提供自动、100%、125%、150%、200% 缩放。自动模式沿用写谱器的 1280×720 基准，最大化与还原窗口会重新计算字号和控件倍率；小窗口自动限制过高倍率，保留可操作空间。手动选择会记住。侧栏宽度和时间线高度按逻辑像素保留，额外空间交给中央预览。

预览双指两轴平移，Ctrl＋滚动围绕鼠标所在位置缩放，W/E/R 当前工具保持高亮；数字输入和箭头连按不会重建正在编辑的输入框。点击工具按钮后 Space 仍用于播放／暂停，文本框里的空格继续正常输入。

素材支持名称搜索、分类和缩略图。对象可重命名、锁定、隐藏、替换素材、复制、分组与生死对称复制。层级数值影响世界对象绘制顺序及镜头视差，默认 0；当前视差系数为 `1 + 层级 × 0.05`。HUD 固定使用正向屏幕坐标，不跟随镜头。

画布基准为 1920×1080，原点在左上。死界对象经过画布中心对称变换；生界和世界对象直接使用画布坐标。分组内部使用父组局部坐标。解组会把父组造成的变换、显隐和颜色变化烘焙到各难度、各区段的子轨，约每秒 60 次采样；一次撤销可恢复。

选区在对象树、预览、时间线与属性之间同步。预览中显示对象轴心、素材声明的发射锚点和运动路径。「路径」也显示所选 BOSS 临近游标的提前弹射曲线。

## 时间线与关键帧

画布栏集中移动、旋转、缩放与对齐；窄窗口的「适应画面」「定位选中」收进画布「更多」。时间线第一行负责播放、循环、吸附和跟随，第二行负责关键帧、片段、自动关键帧和新轨道范围。

位置、旋转和大小的画布操作与数值输入使用同一规则：

- 自动关键帧关闭、没有对应动画：修改基础值。
- 自动关键帧关闭、已有对应动画：整体调整当前区段的对应动画，保留时间和插值。首键前的状态通过区段起点键覆盖，不修改其他区段。
- 自动关键帧开启：更新或创建当前游标的键；已有轨道沿用原难度范围。
- 明确选中关键帧：只改所选键。按 Esc、失焦或打开菜单取消未提交拖动，松手一次撤销。

属性顶部显示编辑目标与作用范围。「高级：直接编辑全局基础值」是明确修改所有区段基础状态的入口。

时间线按对象展开属性与动作子轨。尺标显示秒和谱面节拍，歌曲段落标记沿用谱面。主歌曲和音频片段显示波形。

- 单击尺标定位；上下滚动浏览轨道，横向滚动浏览时间，中键平移；Ctrl＋滚动以鼠标时间为锚点缩放。触摸板两轴独立响应，保留微小滚动量；方向沿用系统。
- Shift＋点击增减选，Shift＋空白拖框追加选，普通空白拖框替换选择；点击多选中的成员保持整组选区。拖动关键帧或片段移动它们，拖片段边缘裁剪，S 在游标处拆分。
- 拖动超过 6 个逻辑像素才修改；一次拖动对应一次撤销，无变化不占历史。Esc、窗口失焦取消当前拖动，Alt 临时关闭吸附；拖动期间独立滚动不改变起点，接近左右边缘自动浏览。删除不推动后面的片段。
- Shift+拖动尺标设置循环区间，也可用「循环范围 → 设置循环起点／终点」（I／O）设置，再开启「循环」。
- 「吸附」选择节拍网格；跨 BPM 的时间仍由谱面 TempoMap 换算。

「跟随」让播放头保持可见；横向浏览、缩放或拖动尺标会暂时停止跟随，上下浏览轨道不暂停跟随。暂停时标示「跟随暂停」，点击或重新播放即可恢复。「视图 → 界面倍率 → 显示整个区段」一键查看当前曲前、歌曲或曲后的完整演出。

透明度、颜色等非变换属性关闭自动关键帧时编辑基础值，开启时记录当前游标；位置、旋转、大小遵循上面的整体调整规则。右侧有常用属性的 ◆ 按钮及「手动关键帧」下拉菜单。选中关键帧可修改时间、值以及保持、线性、缓入缓出、贝塞尔插值。曲线手柄控制该帧到下一帧的变化。

「新轨道范围」只决定新建轨道的范围；已有轨可在右侧「轨道设置」改为所有难度或当前难度。切换难度不会移动公共字幕或镜头。曲前和曲后也各自使用从 0 开始的时间。

## 导入动画与管理引用

1. 左侧「素材 → ＋ 导入 → 动画」打开导入窗口。选择连续图片（多选或文件夹）、整张精灵表或 Godot SpriteFrames（`.tres/.res`）。
2. 连续图片按自然数字顺序排列，可拖动、上移、下移或移除帧。精灵表填写行列或单格尺寸、边距、间隔、有效帧范围，再「应用切割」；辅助线显示实际切割区域。
3. 新图片动画默认 12 FPS、循环。SpriteFrames 保留动作名、帧率、循环、图集区域及单帧时长。帧时长倍率为相对帧率的持续时间，例如 12 FPS 下倍率 2 表示 1/6 秒。
4. 使用棋盘预览、播放暂停、逐帧、时间条、原始尺寸检查。不同尺寸图片保持原尺寸并中心对齐。缺失图片逐项「重新定位」，不会借用本工程同名图片。
5. 动作下拉选择的动作将作为新对象默认动作。点击「导入到素材库」。确认前不写入资源；读取和写入显示进度，可取消。小窗口的表单可滚动。
6. 双击动画或拖入画布，一次创建对象与动作片段、一次撤销。片段从游标延伸到已知区段末尾；未知时取两秒与完整动画周期的较长者。不会自动添加显隐轨，片段外显示默认动作首帧。
7. 在动作片段中选择真实动作、裁剪、拆分、设置偏移、速率、循环及结束保持。回拖和直接定位使用相同时间采样。

对象属性「素材」按类型过滤并支持预览、动作列表、尺寸或时长信息。「清除引用」保留对象及演出；「删除对象」删除对象、子对象和所属演出。替换素材保持 ID 和编排。动作名失效时，问题栏定位到片段，再从真实动作列表重新选择。

「重新导入此动画」创建新资源版本，一次更新当前引用；旧文件保留以支持撤销。「素材 → 清理未使用素材」先列出清单，再移入工程 `.unused/`，仍可取回；当前文档、撤销和恢复稿引用的文件会保留。

「定位使用此素材的对象」同步选中对象树与画布。多选属性标示共同值或「多个值」；画布「对齐」提供左右、上下、中心对齐及等距分布，父子同时选中时只变换选区根对象。

## 背景前后关系

背景制作端选择深度层后可「命名背景层」。关卡属性显示「名称 · 深度」，留空时显示「深度 N」。对象可沿用父组、不参与、位于某背景前或后，并显示最终生效关系。即使没有同深度素材，该数值位置仍保留，换景不自动猜配。

遮挡只改变显示位置，不让对象跟随背景子层滚动。切回不参与或 HUD、删除、撤销及重装会正确解除挂载。素材内部 z 顺序无法越过指定背景前后边界。隐藏、锁定或受父组限制的对象不参与编辑；右键重叠位置可按对象名和层选择。

## 动作、环境、HUD 与音频

选中角色或场景对象后「添加动作」，选择素材已提供的动画或状态，设置长度、素材偏移、播放速率、循环、淡入淡出与结束保持。重叠的 AnimationPlayer 属性按片段顺序和权重混合。

选中多个对象，在左侧「片段 → 保存选区为演出片段」保存当前区段的组合；「插入演出片段」在游标处展开为独立对象和轨道，随后可继续编辑。已插入实例不会随模板修改而改变。

环境对象可使用多个场景，通过「显示区间」设置出现范围及淡入淡出。换景只改变演出对象，正在运行的歌曲、Hold 和调频继续处理。镜头对象提供位置、缩放和震动，影响世界演出对象，不改变音符判定路径。

HUD 文字可设置字体、字号、区域尺寸、对齐、颜色和显示区间；给「打字进度」从 0 到 1 加关键帧可做打字机效果。图片同样支持透明度、移动与显示区间。

音频对象添加音频片段后，可裁剪、偏移、循环、调速、设置增益及淡入淡出。对象的音量关键帧构成整体包络。「独立试听此片段」用于听选中声音；完整包络和重叠效果用时间线播放检查。瞬时音效在拖动定位时不补播；持续声音从当前位置恢复。暂停、循环和跳转会清理旧播放实例。

## BOSS 攻击

1. 先在写谱器给 Tap、Hold 或素音勾选「BOSS 发出」，保存并刷新关联谱面。
2. 选中 BOSS 对象，点击右侧「BOSS」或对象属性的「绑定 BOSS 音符」，在主工作区编排。
3. 选择音符和素材动作，点击「创建绑定」；已有绑定直接逐字段编辑，每次手势可撤销。双击列表音符定位主时间线。
4. 首次选中动作即读取素材出手标记；局部动作时间与歌曲时间分别显示，可用「将当前动作帧设为出手帧」。面板列出动作开始、发射、入轨和判定时间，包括负时间。
5. 锚点使用素材声明的列表，音效与特效使用可搜索的素材选择器。命中／失误预览针对当前绑定。
6. 「复制动作配置并重新选音符」创建不带音符关联的草稿；普通对象复制携带演出轨道，但不重复 BOSS 音符关联。

界面优先显示素材名称；鼠标提示保留 ID 或相对路径用于核对。手柄以发射点为原点，入轨端切线由正常进场方向和速度决定。

动作自动倒推：入轨 = 拍点 − 正常进场时长，发射 = 入轨 − 回转时长，动作开始 = 发射 − 出手帧时间 ÷ 动作速率。默认回转 0.60 秒。同刻音符共用动作；连续音符可放在一个绑定中，修改绑定统一调整这一段。

时间线上带「自动编排」的 BOSS 行由绑定生成，点击进入对应绑定编辑。Tap、Hold 在提前段和正常段使用同一个实例；起点冻结为出手帧的锚点位置。素音标记只驱动动作和特效，素音本身继续由真实声波关系生成。

「检查命中反馈」「检查失误反馈」用于查看所选对象的反馈。正式游戏使用实际可见判定／接触事件，同刻反馈合并，反馈叠加不会取消下一次攻击。

## 保存、素材更新和试玩

- 「保存」写入关卡、演出和工作区；「另存为」复制当前工程所需歌曲和素材。已有文件保留 `.bak`，写入中的临时文件使用 `.tmp`。
- 文档改动后约 1 秒生成按工程区分的恢复稿。「文件 → 查看恢复稿」列出时间与对象／轨道摘要。恢复前另存当前未保存状态，恢复后保持未保存；旧单文件恢复稿仍可读取。原素材文件仍需存在。
- 普通导入创建独立文件，同名不会覆盖旧引用。替换素材保留对象与编排，旧文件供撤销。PCK 更新先准备新版本，选择「重启并应用」恢复未保存文档、布局和历史；「稍后」继续使用当前版本，可从素材菜单再次应用。版本切换的撤销也需要重启，不强制保存正式工程。
- 缺失素材会列在底部；双击定位相应难度、区段和事件。修复指定引用只替换此处；动画内部图片修复生成新描述版本，模板独占引用也可定位与修复。
- 试玩使用启动时的未保存关卡快照，显示启动、加载、已加载或失败状态。编辑器在后台暂停预览与声音并降到 10 FPS；返回前台立即恢复编辑，即使游戏仍打开，声音需主动播放。
- 曲前不改变谱面偏移，重试跳过曲前；歌曲正常结束先固定成绩，再播放曲后，最后结算一次。

新素材只要遵守现有接口，不需要重建工具。新增原生扩展或改变运行接口时，工具和配套游戏需同步更新。

## 操作稳定性与工作区恢复

对象树、画布、时间线和属性同步同一选区；属性获得焦点不会改变删除、复制、粘贴的目标。关键帧多选支持整体平移、共同值和插值批量调整。对象多选的差异值显示「多个值」。锁定或隐藏父组同时约束子对象；父子同时选择时不会重复变换。

数值连调、调色和曲线拖动实时预览，一次手势一次撤销。曲线空白处不会拾取远处手柄，精确控制点也可用数值修改。文本框中的空格、复制、删除和撤销用于文本；Ctrl＋S 先提交当前字段再保存。模态窗口关闭后恢复原焦点。

时间线默认 24 逻辑像素行高，折叠行仍可命中事件；秒尺、节拍、只读谱面参考和波形各有位置。重叠事件用右键选择，菜单也提供复制、粘贴、删除及拆分。

定位时游标立即响应，正式预览每 50 ms 最多接收一个拖动目标，释放后精确定位。超过 200 ms 才显示「正在加载和定位」，期间保留最后完整画面。普通改名和调色不重建玩法或重新编译攻击。

无问题时问题栏完全隐藏，有问题时显示数量，展开后点击定位。面板宽度、高度、显隐及各区段／难度的选区、折叠、时间线、循环和画布视图随工程保存；恢复稿显示记录时间与对象数量。打开工程不会用初始化内容覆盖旧恢复稿。

源码中未指定配套游戏时，「在游戏中试玩」可直接用当前 Godot 引擎启动 Game，使用未保存快照，无需导出 EXE。已交付程序继续使用其配套游戏。


## 可靠性与连续制作（2026-09-14）

- 多选数值输入是绝对值。只改位置 X 或大小 Y，其余分量保持各对象原值；画布拖动保持相对距离。差异值逐分量显示「多个值」，同类对象切换复用字段。锁定或受隐藏父组约束的成员使整次批量编辑拒绝；解锁、显隐仍可操作。
- 普通粘贴保留来源对象，落到当前区段，以最早事件对齐游标。公共轨仍公共，专属轨落到当前难度；跨区段／范围创建新轨。同轨同时间关键帧替换值与插值并保留目标 ID。「编辑 → 粘贴到选中对象」要求单来源对象及单个兼容目标。撤销、重做恢复对应选区。
- 对象树可搜索、按类型筛选、行内显隐／锁定；拖动改变父组与顺序时保留显示变换及生效遮挡。跨父组的动画按制作帧率烘焙，长动画生成的键会更多；撤销恢复原轨道。
- 时间线的「轨道视图」提供全部／所选对象、当前难度、隐藏空轨、前后事件与适应选区。筛选随各区段／难度视图保存，不删除或改写数据。图片、动画和声音拖到时间线分别创建对象与显隐、动作、音频片段；一次撤销。字体拖到画布文字对象设置字体。
- 「视图」提供布置、动画、BOSS 布局预设。侧栏边缘按钮可折叠；窄窗口低频操作在所属工具组的「更多」中。空工程的起步引导可从帮助重新打开。
- 动画导入可追加图片、重命名动作、从所选帧建立新动作；帧序号、素材时间与跳过文件均有明确读数。切换来源先确认替换候选，取消不改已导入素材。素材列表默认隐藏动画内部图片，提示来源、类型、引用数量和已加载的尺寸／时长。
- 左侧「片段」列出模板的名称、区段、时长和对象数，支持命名、预览、删除、插入。模板独占图片、字体关键帧和动画依赖会被另存和打包；清理保留文档、历史及恢复稿依赖。
- BOSS 音符按类型、生死侧、时间段和绑定状态筛选；「全选筛选结果」保留其他已选音符。动作滑条始终是素材时间，动作速率不改变读数；图片动画按各帧实际时长逐帧。多音符绑定列出每个音符的时序及覆盖范围。
- 环境属性显示前一环境与目标，逐层列出等待、入画和完成；点击层名可单独查看并定位。完成时间包含淡化带退出，仍由正式环境安排计算。
- 「整关审片」从曲前连续进入歌曲与曲后。开始字段编辑或拖动会暂停并固定目标；继续播放需主动操作。退出恢复进入前的区段、游标、循环与视图，保持暂停，保留修改。
- 导出先显示难度、依赖、错误和原始大小估计，压缩显示进度并可取消；完成后可打开输出目录。另存复制和准备试玩快照也显示进度。试玩失败可从「工程工具 → 试玩日志与重试」查看日志并重新启动。

扩展的 `examples/level-studio/渡口演出/level.json` 包含循环相纹动画、0.5 倍速动作、结束保持以及可独立插入的动画模板。建议另存到新目录，删除原动画对象后插入模板，再整关审片与试玩，验证资源没有依赖原对象的存在。

当前覆盖与未实测项见 [本轮验收记录](level-editor-reliability-validation-2026-09-14.md)。

SpriteFrames 的 `.tres`／`.res` 拖入窗口后，会进入动画导入窗口。检查动作与图片后确认，编辑器将生成独立动画描述并复制实际图片；不能仅把原资源文件复制进素材目录。自动选择动作时跳过空动作（包括 Godot 自带的空 `default`）。如果旧版本拖入后对象不显示，请使用「素材 → 导入动画 → Godot SpriteFrames」从原资源重新导入，选中有图片的动作，再绑定给对象；缺失图片会在导入窗口逐项提示。

初始环境可从右侧「关卡设置 → 选择初始环境」或「环境场景」属性进入。选中列表项后点击「使用此场景」，也可双击；仅搜索或取消不会修改关卡。确认后名称与预览立即更新，再次打开会选中当前环境。使用「恢复沿用基础场景背景」可取消独立环境，撤销／重做会同步这些状态。此入口修复的点击与画面证据见 [初始环境验收记录](level-editor-initial-environment-validation-2026-09-15.md)。

「最近工程」「查看恢复稿」需先选择列表项才能确认；取消恢复或打开失败后，当前工程继续保留自动恢复。素材选择器搜索无结果时停止旧预览，图片动画逐帧按实际帧时长定位。素材拖入失败不会改动原选区。相关问题与回归范围见 [操作入口复查](level-editor-entrypoint-audit-2026-09-15.md)。

### BOSS 骨骼动画

从「素材 → 导入骨骼动画」或素材栏「＋ 导入 → 骨骼动画」进入，也可拖入 Spine `.spine-json`、骨骼 `.json` 或 `.skel`。选择骨骼后自动带出同名 `.atlas`；图集不同名时点击「选择对应图集」。图片需位于图集声明的相对路径，缺图会显示具体文件。

导入窗口可选择动作、播放暂停、按 60 fps 逐帧、拖动动作时间，以及设置显示比例和当前动作的出手标记。确认前不写入工程。确认后骨骼、图集及所有图集图片复制到独立素材目录；再次导入生成独立素材，不覆盖原文件。拖入画布创建 BOSS / 场景对象，并从当前游标创建动作片段，一次撤销同时移除两者。

先导入歌曲、选中该对象，再打开 BOSS 绑定。动作列表、默认动作、动作长度和出手标记来自导入素材；其他音符选择、动作速率、局部预览与绑定流程保持不变。保存、另存和 ZIP 包含骨骼及图集图片，不依赖原始素材目录。

骨骼数据需与当前 Spine 4.3 运行库匹配。旧版 3.8 数据请重新导出；工程的特定 BOSS 转换脚本不是通用转换器。导入的是骨骼动作本身，审看工具脚本额外生成的光效、碎片和阶段逻辑仍需通过现有 Godot 素材包接入。本轮没有重建 EXE。

### BOSS 音符协作查看

时间线播放栏的「BOSS 音符总览」无需先选对象即可打开，统计当前难度的 BOSS 音符、未绑定音符和失效关联。可搜索时间、类型、音符 ID 或所属对象，按绑定状态筛选，并定位上一／下一枚筛选结果。切换难度后查看对应谱面。

底部独立 BOSS 参考轨用橙色表示未绑定、绿色表示已绑定、红色表示失效关联；Hold 显示完整持续范围。悬停可查看时间、类型、生死侧及所属对象／动作。已删除或取消 BOSS 标记的失效音符没有可信时间，只在总览中列出，不猜配到其他音符。

点击参考标记或双击总览条目只定位和查看，不增删绑定。选中一个 BOSS 对象后，可明确点击「加入绑定」将音符加入当前绑定或新建草稿；已有来源不会自动移除。修改已有绑定可一次撤销，草稿需按原流程确认创建。

骨骼导入窗口播放按钮会显示「播放／暂停」。已修复时间变化但骨骼画面静止的问题，共享修复同时用于导入预览和关卡演出预览；验证包含播放、暂停及回拖的实际像素比较。覆盖范围见 [BOSS 总览与骨骼播放验收](level-editor-boss-overview-playback-validation-2026-09-15.md)。
