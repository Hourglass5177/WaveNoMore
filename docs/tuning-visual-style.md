# 调频滑条表现

2026-09-13。正式游戏与写谱器内嵌预览共用 `GrayboxFieldVisual`，本次不改滑条路径、角行程、调频输入或判定。

## 外形与颜色

- 圆帽与条身合成一张外形，骨白描边只画外轮廓；不在半透明底色下面铺实心描边，也不重复叠画圆帽。
- 起点计时缩圈裁去朝条身内部的弧段，保留端点外侧的提示。方向箭头、折返、序号和起手时刻沿用现有逻辑。
- 生侧使用低饱和灰青 `#597880`，死侧使用赭红 `#87382E`；骨白为 `#E6DDC9`。与当前生／死音符的蓝／红映射一致。
- 轨道宽度仍为 104 px，描边改为 3 px。底轨不透明度 0.34，填充不透明度 0.68，贴合时 0.76；这些是各层 alpha，底轨叠加后的普通填充实际 alpha 约 0.79。

## 起点预填与柔光

起点预填默认只有 2 px 中心线延伸，与 104 px 宽的圆帽组成近似圆形的阵营标记；短轨最多占中心线长度的 16%。预告阶段就能看到；正式操作时显示填充取预填与实际填充的较大值。预填只参与绘制与光效，不写入玩家位移、问题检查、谱面或 Replay。折返使用新一程的起点，失败后不保留预填和光效。

轮廓为骨白柔光，默认强度 1.0、外扩 18 px；填充为所属阵营的面光与外晕，默认强度 0.8、外扩 24 px。开启参数、强度、范围、两侧颜色、透明度与预填长度均可在 Inspector 的 Tuning 分组调整。

每条滑条的轨道柔光使用一个局部网格和独立材质，读取既有圆心、半径、起始角、角行程及本程填充区间；shader 直接求圆弧胶囊距离，无逐像素采样点循环、无额外灯光或视口。起点缩圈另用一个合并弧段的提示网格，采用略偏青绿／暖铜的阵营色，详见 [计时提示参数](timing-cue-style.md)。光效不使用独立时间或随机状态，填充回退、换向和对象池回收同步更新。网格范围外及内部无光区域保持透明。

轨道底色、填充和描边现共用固定局部网格，以 shader 圆弧距离求外形；填充位置改变只更新参数，不再生成填充多边形。起点缩圈仍用 Geometry2D 裁切，但主线、托底和柔光复用同一结果。性能与 2K 坐标适配见 [关卡性能与分辨率](performance-and-resolution.md)。
