## 配色与参数

全局资源为 `content/presentation/timing_cue_style.tres`，由 `NoteVisualHost` 注入音符环和调频条；独立实例也默认使用同一资源。它引用现有 `NoteEffectStyle`，不写入谱面或 Replay。

Tap／Hold 提示与本体有轻微色差：生侧在青蓝基础上略偏青绿，死侧在赭红基础上略偏暖铜。调频起手缩圈和键位直接使用对应音符亮部与光晕色，不偏移色相。主线混入 30% 骨白，进度端点和闭合标记使用骨白。SU 仍为骨白。Inspector 参数如下：

| 参数 | 默认值 |
| --- | --- |
| Tap／Hold 整体不透明度系数 | 0.90，与判定淡出相乘 |
| 生／死提示色相偏移（HSV 一圈为 1） | -0.045／+0.025 |
| 主线骨白混合比例 | 0.30 |
| 音符进度亮弧／接近缩圈线宽 | 6／3 px |
| 接近缩圈不透明度 | 0.45 → 0.75，平滑增加 |
| 进度亮弧光晕宽度／强度 | 10 px／0.55 |
| 接近缩圈光晕宽度／强度 | 8 px／0.40 |
| 调频起手缩圈半径 | 136 → 源泉半径（默认 52 px），先小幅抛起、再加速落下 |
| 调频缩圈主线不透明度／柔光强度 | 0.65 → 0.90／0.55 |
| 判定圈键位不透明度／柔光半径／强度 | 0.58／6 px／0.28 |

摇杆底座固定在滑条原始起点，使用源泉的大圆外框（默认半径 52 px）。帽面直径为底座直径的 48%，默认约 50 px；帽面与侧壁基础不透明度为 0.84；回中为正圆，满推时沿推动轴压缩至 88%，形成轻微向外倾斜，切向尺寸保持原值。帽面中心沿物理向量方向移动，满推时外沿恰好抵住底座外框。缩小后满推中心偏移由约 24.5 px 增至 30 px，转动幅度更清楚。没有固定向上偏移或额外 Y 轴压缩。配色使用音符色板，薄侧壁与上缘柔亮边辅助辨识厚度。固定四边形默认 120×120，只更新 uniform，不按帧创建节点或重建帽面网格。帽面位于条身之上、完整缩圈之下，起点附近的点列避开帽面。键位保持原位置与 36 px 高度，柔光遮罩在设备切换时生成并按图标缓存。

`note_opacity` 通过音符环节点统一调制主线、托底、标记和柔光；多层覆盖处最终 alpha 仍按正常透明混合叠加。该系数不作用于滑条缩圈或中央判定框。

## 绘制与时钟

`TimingCueGlow` 共用一个 Compatibility `canvas_item` shader，每个提示实例复用自身网格和材质。普通音符环使用固定四边形，由 shader 同时求进度亮弧和接近缩圈，只更新 uniform；进度运动不会重建 GPU 网格缓冲。滑条缩圈采用完整弧段的带状网格，只有几何或样式改变时重新提交；暂停不重建。

提示不读 shader TIME，也不创建灯光、SubViewport 或粒子。提示位于现有稳定 HUD 层，声波折射不会改变其位置。Tap 命中立即隐藏主线与光晕；Hold 头命中不再提前淡出持续环，尾部结果触发收尾。Miss 关闭阵营光并沿用灰色失败提示。

`TimingRingVisual.set_visual_time()` 接收宿主绝对视觉时间。反馈记录事件时刻，以事件年龄计算原有 0.13 秒缩放与 0.15 秒淡出；重复事件不重置，暂停冻结，回退恢复，回收清空。色板和线宽入口集中到 `TimingCueStyle`，旧圆环的独立生死颜色与线宽导出属性已移除。

## 密集提示开销

2026-10-10 调频专项：RTX 4060 Laptop、Compatibility、1920×1080，32 条双侧滑条交替使用 HEAD 旧表现脚本与当前脚本，每段预热 30 帧、采样 180 帧。两轮旧版整帧平均为 15.09／17.64 ms，P95 为 18.91／23.52 ms；新版平均 9.64／11.68 ms，P95 为 12.66／15.58 ms。GPU 平均旧版 1.19／1.26 ms、新版 0.28／0.32 ms；首次四帧最大旧版 42.20／24.69 ms、新版 19.94／16.30 ms。新版每条新增一个固定帽面节点，总节点 179，在每段前后不增长（旧版 147）。旧循环弧的逐帧折线绘制已移除。结果仅说明此隔离场景未出现开销回退，不能等同于整关卡性能或承诺固定帧率。

`measure_timing_cues.gd` 在 RTX 4060 Laptop、Compatibility、1920×1080 下绘制 48 个持续运动的计时环，依次关闭／开启／关闭／开启柔光，每段预热 30 帧后采样 300 帧。结果保存在 `builds/timing-cue-review/performance.json`。

| 状态 | 整帧平均 / P95（ms） | GPU 平均 / P95（ms） |
| --- | --- | --- |
| 关闭，第 1 段 | 14.13 / 18.12 | 0.624 / 1.293 |
| 开启，第 1 段 | 16.60 / 19.93 | 0.806 / 1.946 |
