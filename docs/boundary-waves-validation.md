# 波浪分界线重构验收

日期：2026-09-14。Godot 4.7.2，Compatibility，NVIDIA GeForce RTX 4060 Laptop GPU。未构建发行程序，保留工作区其他修改。

## 水流强化与中央裁切修复

- 水流默认速度由 36 提到 60 设计 px/s，原纹混合强度由 55% 提到 80%，细纹由 14% 提到 24%。双阶段权重改为平方归一化，减少两组反向位移对宽色带运动的抵消；底带透明轮廓仍固定。
- 移除大小浪材质中半径 70 设计 px 的圆形透明裁切。浪花保留完整轮廓，在判定圈后方绘制，由实际界面层级遮挡；中央的底带颜色流动减弱继续保留，不影响透明度。
- Compatibility 波浪专项 **113 项、0 失败**，新增源图与中央浪花的透明覆盖逐像素对照。策划参数专项 **85 项、0 失败**。工作簿明确更新上述三项当前值，其他人工当前值保留；错误扫描通过，并检查修改前后表格渲染。
- 在实际关卡的 1920×1080 和 1280×720 下采样双 Hold、调频及主角攻击同场画面，确认中央缺口消失、判定圈仍清楚。未增加纹理采样或绘制次数，本次未重新测量 GPU 耗时。
- 输出原生全景 `build/boundary-animation/water-flow-boost-60fps.webm` 与同刻前后对照 `water-flow-boost-comparison-60fps.webm`，均为 4 秒、240 帧、60 fps；中央裁切对照为 `flow-boost-center.png`，关内画面为 `flow-boost-stage/game-1280.png`。本轮不构建发行包。

以下保留此前修订记录，参数与测试数量以各次检查时的版本为准。

## 基底原纹与细水纹流动

- 正式底带已接入 Flow Map 与双阶段颜色搬运，并在同一次绘制中混合原画提取的细水纹。默认 36 设计 px/s、原纹 55%、细纹 14%；透明轮廓和外缘固定，中央减弱。两界流向中心对称，水流独立于 BPM。
- `run_boundary_motion_tests.gd`：**112 项、0 失败**，Compatibility 原生渲染。新增基底单独渲染检查：开关与原纹一致、负时间/循环边界/长时间采样透明度逐像素一致、暂停、远跳恢复、完整周期、仅原纹模式及不同 BPM 下同秒画面一致。原有换景、两种分辨率及静态原画回退继续通过。
- `run_planning_parameters_tests.gd`：**78 项、0 失败**。真实 XLSX 读入四项水流字段，修改应用到表现副本，Replay 规则摘要不变。
- 控制图方向的中心对称误差不超过 8 位量化的一级，作用权重和相位中心对称一致。工作簿同步前后核对全部已有单元格值和公式，无变化；新增四行，重新计算与错误扫描通过，查看了修改前后页面渲染。
- 输出 120 BPM、6 秒、360 帧、60 fps 的三个同步状态；检查完整水带、局部细纹、中央连接和多次循环。另在 s08 的 41 秒位置检查双 Hold、相纹、调频及主角攻击，分别采样 1920×1080 与 1280×720。

GPU 检查保持活动浪和关内姿势一致，只切换基底水流，每组 240 个有效采样帧，不含截图编码：

| 视口 | 水流关闭：中位数 / P95 | 水流开启：中位数 / P95 |
| --- | --- | --- |
| 1920×1080 | 2.589 / 3.622 ms | 2.449 / 3.494 ms |
| 1280×720 | 1.670 / 2.887 ms | 1.729 / 2.950 ms |

这是本机整场 GPU 采样，差异包含驱动波动，不说明开启更快，也不代表其他设备。底带仍为一次绘制，未引入运行时图像生成或全屏后处理。

本次交付位于 `build/boundary-animation/`：`water-flow-full-60fps.webm`（原生全景）、`water-flow-close-60fps.webm`（底带近景）、`water-flow-comparison-60fps.webm`（三状态），均已核对解码、帧数与帧率；`flow-stage/game-1280.png` 为关内画面，`performance-flow.json` 保存性能结果。素材再生成与材质说明见 [波浪接入说明](boundary-motion.md)。本轮不构建发行包。

## 原画底带与小浪上提修订

- 小浪上移 6 设计 px，纵向比例 0.26 → 0.30，约增加 15%；浪根继续嵌入水带，死界中心对称调整。沿用连续轮廓补间和既有时序。
- 移除原先近水平的上下裁切。底带保留原画的厚薄变化和天然走势，仅在八处静态高浪的浪根外局部压缩，保留薄白边，形成低水脊；原始 `edge.png` 不改动。
- 原生 Compatibility 波浪专项仍为 97 项、0 失败，覆盖暂停、定位、换景、两种分辨率和静态回退。素材检查新增原画水带内部及未处理轮廓的逐像素核对，通过；水带中心行连续，257 个骨骼姿势无三角形翻折。
- 新版 120 BPM、4 秒、240 帧、60 fps 全景及同刻对照分别为 `build/boundary-animation/waves-relief-60fps.webm`、`waves-relief-comparison-60fps.webm`；比例静态对照为 `waves-relief-comparison.png`。正式关内两种分辨率截帧位于 `relief-stage`。
- 本次只调整底带生成与小浪布局，未新增运行材质、图集或实例；未修改策划字段和工作簿当前值，未构建发行包。

## 浪形比例与流畅度修订

同日根据审看反馈提高小浪纵向幅度约 37%，横向略收窄；中央大浪横向略收窄，保留配置浪高。水面锚点、中心保护区、逐拍出生与小节触水时刻不变。

- 小浪由 32 帧抽样改为完整 128 帧；大小浪均增加相邻帧的连续预乘补间。生成阶段以单调时间曲线衔接关键姿势，减少反复减速停顿。
- Compatibility 专项更新为 **97 项、0 失败**。新增固定骨骼和位置后，仅改变整数帧内年龄的像素检查，确认大小浪均发生实际轮廓过渡；原有暂停、定位、换景与静态回退像素检查继续通过。
- 几何复核：128 个附件、257 个骨骼姿势，最小三角形面积约 500.54，水带连续。
- 修改前后分别输出原生 1920×1080、4 秒、240 帧、60 fps 采样。检查卷顶、下扣、摊开与接替的阶段图，并在 s08 双 Hold、相纹及主角攻击同场的 1920×1080、1280×720 截帧中检查遮挡。
- 本次整场 GPU 采样每组 240 帧：1920×1080 静态中位数/P95 为 2.909/5.870 ms，动画为 2.784/5.780 ms；1280×720 静态为 2.534/6.532 ms，动画为 2.664/8.693 ms。整场测量有波动，不据此声称动画更快。图集仍为一张 4096×4096，各浪增加一次邻帧采样。
- 未修改策划可配置字段、默认值及工作簿人工当前值；未构建发行包。

## 性能采样

同一 s08 41.2 秒姿势交替开关动画，每组 240 个有效采样帧；GPU 计时不含截图及 PNG 编码。

| 视口 | 静态 GPU 中位数 / P95 | 新动画 GPU 中位数 / P95 |
| --- | --- | --- |
| 1920×1080 | 4.321 / 13.050 ms | 4.174 / 12.431 ms |
| 1280×720 | 2.977 / 12.477 ms | 2.729 / 11.503 ms |

这些是整幅关卡的采样，存在驱动与其他表现的波动；数值不足以说明动画更快，但没有观察到明显增加。四个 Spine 实例及六个小浪精灵常驻，纹理共享，运行时不生成图集或计算光流。换景重叠期间会有两份背景组合。
