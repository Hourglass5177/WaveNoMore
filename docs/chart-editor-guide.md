# 冥河写谱器使用说明

当前是开发版，支持生／死 Tap、Hold。调频 Hold 和素音尚未接入；完整验收进度见 [开发记录](chart-editor-progress.md)。

## 开始一张谱

1. 运行 `minghe-chart-studio.exe`，不需要安装 Godot。点击“导入音乐”，首次使用时先选择一个项目目录，再选择 WAV、Ogg Vorbis 或 MP3。
2. 在左侧填写歌曲、作者；在右侧设置首拍偏移和 BPM。偏移单位是毫秒，允许小数；用波形和节拍辅助尺对齐。点击时间尺定位。
3. 下方上轨是生钟，下轨是死钟。空白点击画 Tap，沿时间拖动画 Hold；反向拖画也有效。超过 6 像素才成立为拖画。
4. 空格试听／暂停。上方会自动演示正式关卡表现；定位到 Hold 中段会恢复持续状态。大谱定位时显示“正在定位…”，可再次定位取消旧请求。
5. Ctrl+S 保存，重新打开项目里的 `song.json`。交付时点“导出谱面”，选择需要交付的难度。

音符横向位置表示要求起手的时刻。背景里的生成、接近和波传播由游戏规则计算。

## 播放控制栏

三角图标播放，播放时切换为暂停图标。左箭头加竖线返回音乐开头；循环箭头高亮表示循环已开启。悬停可查看按钮含义和快捷键，循环起止按钮还会显示当前范围时间。

“倍速”选择试听速度；“吸附”选择音符细分或关闭吸附。窗口缩小时工具栏按组换行，左右侧栏可滚动，专业字段仍直接显示。难度标识用于文件名；起始位置、时长和全谱偏移保留 tick 单位。

## 常用操作

| 操作 | 方法 |
|---|---|
| 选择、移动 | 点击音符选中；拖动已选成员移动选区 |
| 多选 | Shift 点击增减；Shift 在空白拖动框选 |
| Hold 头尾 | 拖头固定尾，拖尾固定头 |
| 自由拖动 | Alt 临时关闭吸附 |
| 平移、缩放 | 中键拖动；Ctrl+滚轮围绕鼠标缩放 |
| 取消手势 | Esc；窗口失焦也取消尚未提交的手势 |
| 复制／粘贴／剪切 | Ctrl+C／V／X，粘贴锚定游标，完整双押重新生成组标识 |
| 重复、生死互换 | Ctrl+D、Ctrl+M；也可用右键菜单 |
| 删除 | Delete，不推移后续音符 |
| 量化 | Q 量化起始位置并保留时长；Shift+Q 量化起止位置 |
| 撤销／重做 | Ctrl+Z、Ctrl+Shift+Z 或 Ctrl+Y |
| 步进输入 | 暂停时按 F／J 输入生／死；按住并移动游标可输入 Hold |
| 移动游标 | 左右方向键按吸附步长移动；PageUp／PageDown 按当前小节长度移动 |
| 循环 | “循环起点”（I）和“循环终点”（O）设置范围；循环箭头按钮或 L 开关循环 |

编辑器 F／J 对应时间线的生／死顺序。游戏自己的物理键位由游戏侧维护。文字框获得焦点时，空格、F、J 用于输入文字。属性输入可按 Enter，离焦也会提交；保存前会提交正在输入的属性。

右侧支持批量音符属性、分组、时间变化、段落名称、内置主题和配色。复制难度后可在右侧修改难度标识。试听倍率为 0.5、0.75、1、1.25、1.5；节拍器和音符提示音分开控制。

## 保存、恢复和旧谱

项目包括 `song.json`、`charts/`、`audio/` 和本机视图状态 `editor/workspace.json`。移动项目时一起移动整个目录。音频失去关联时用“导入音乐”重新指定文件。

未完成或有玩法冲突的草稿可以保存。“问题（数量）”可展开或收起列表，点击问题可定位对应时间；新问题自动展开，问题修正后自动收起；不可解释的音符不会悄悄进入旧预览。正式 ZIP 导出会检查所选难度，并排除工作区状态、缓存和迁移归档。

修改提交后等待 1 秒生成恢复稿，连续修改会合并；录制结束立即更新。恢复提示显示保存时间、歌曲及各难度音符数，恢复后重新生成波形并回到原难度和视图。异常退出后再启动可恢复；正常退出提供保存、放弃、取消。上一版文件另有 `.bak` 备份。

导入旧 `.tres` 时选择旧关卡入口和新的目标目录。只转换 Tap/Hold 和可表达的数据，原文件与依赖保存在 `legacy/`，差异见 `legacy/import-report.json`。旧关卡只有程序占位音频时，需要另外导入歌曲。另存为会复制迁移归档。

设备试听补偿属于本机工具设置，和歌曲首拍偏移分开。保音高质量、同步与密集谱面性能的实测限制请看开发记录，暂不把本开发版当作已完成正式验收的发布版。


## 实时录入与时间线

先点击“录制”（R），再播放音乐。F 输入生钟、J 输入死钟；短按不超过 150 ms 为 Tap，较长按住为 Hold。可在右侧“试听”的“长按判定（ms）”调整阈值，按真实按住时间计算，慢速播放也不改变短按手感。音符起止跟随当前吸附；关闭吸附则按 tick 记录。

松开的音符立即显示在时间线上；本轮播放仍演示录制前的谱面。暂停、关闭录制或音乐结束，才一次性提交本段，可用一次撤销移除。失焦、打开对话框、主动定位或更换吸附时结束当前段，丢弃尚未松开的键，保留已完成音符。循环回绕截断长音，须松键后才能再次录入。循环边界不足一格时尾段会短于吸附步长；吸附后没有可用时长则保留为 Tap，不跨到下一轮。文字输入时 F/J 不录音符。

时间线上方是秒标尺，音乐零点有贯穿轨道的零刻线；负时间区有底色，首拍单独标注。拖动标尺或波形定位，拖动循环起止把手调整范围。滚轮横移、中键拖动、底部滚动条用于浏览；拖动音符到两侧边缘会自动滚动。手动浏览暂时解除播放跟随，重新播放或点击“跟随”恢复。

“视图”菜单提供自动界面缩放、100%／125%／150%，以及显示整曲、显示选区。自动缩放随窗口增大同步放大按钮与文字。

拖动配色时即时预览，关闭颜色弹窗提交一次修改；一次撤销恢复弹窗打开前的颜色，不打断音乐。
