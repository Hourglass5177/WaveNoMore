# 动画与遮挡制作示例

在当前源码关卡编辑器中打开本目录 `level.json`，建议先另存副本。2026-09-13 构建的 Levels/minghe-level-studio.exe 已支持本示例。

示例包含三份统一动画资源：连续图片、精灵表区域、不等帧时长的 SpriteFrames 动作；三条动作轨采用不同偏移与速率。扩散环是测试图形，不代表正式美术。歌曲沿用渡口测试拍，含 normal/hard 两个难度。

1. 播放、暂停并回拖，观察三组扩散环。
2. 选择某个动画对象，关闭自动关键帧后拖动；观察位置轨整体改变，其他区段不动。撤销，再开启自动关键帧，在新时间点移动。
3. 拖动动作片段端点、在内部拆分并改变速率，检查偏移连续性。
4. 选择“扩散环组”，改变背景层及前后位置；子对象默认继承。选择子对象可明确停止继承。
5. 选择“空引用对象”，在素材栏重新绑定动画。清除引用、撤销、替换素材，确认对象与位置轨保留。
6. 另存到新目录，或导出 ZIP 后从独立目录打开。动画依赖均在本工程中。

素材描述见 `assets/animations/`。示例由 `tests/editor/build_animation_example.gd` 生成；不会导出可执行程序。
