# 预览加载与定位优化（2026-09-14）

基于 `editor@54d78b5` 现有工作区，保留并行的随从、关卡编辑器改动；未合并分支。第二关、教程2及其他用户谱面未改写，游戏未重新导出。

## 实现

完整运行正式领域模拟，索引实际判定、接触、抵达记录，再恢复目标仍可见对象需要的运动。首次访问更晚时间先做领域探测，再运行正式会话恢复；重复访问复用探测记录。Ghost 仍由正式模拟计算，不截取局部谱面重新判定。

活动 Hold 保留 120 Hz 积分；已离场音符不创建表现节点，可见性取真实结算、反馈寿命及失败离场曲线边界，BOSS 生成时间取正式调度器。Tuning 控制与正式圆弧共享几何。角色在按住、频率和反应边界推进 Spine 轨道、混合与动作转换，最终才更新骨骼世界变换和网格，不跟随身体每步更新。

每 0.5 秒缓存持续 Hold 的头部、目标、链条位置、角速度和积分余量。仅在内存保存，按序列化状态大小估算 64 MiB 预算并淘汰最近最少使用项；容器还有额外开销。编辑按修改前后最早实际生成/准备时间失效后续样本，规则、场景配置、谱面身份或偏移改变清空。颜色、选择、缩放走原轻量路径。

工作区校验、转换、编译共用一次结果，装载复用关卡实例；JSON 不变。历史约每 12 ms 让帧，保留最新请求取消、最后完整画面和延迟 200 ms 蒙版，不补播历史声音。

## 实测

Core Ultra 9 185H，Godot 4.7.2，headless，60 FPS 调度。第二关含 165 Tap、57 Hold、34 Tuning、0 Ghost。后台编辑器及其他任务仍运行，存在负载波动；这些不是 GPU 帧率数据。旧恢复冻结在 `tests/editor/slow_preview_session.gd`，新旧使用同一当前领域及表现资源。

| 音乐位置 | 旧恢复 | 优化后多轮 |
|---|---:|---:|
| 60 秒 | 1.56 秒 | 0.72～1.10 秒 |
| 120 秒 | 15.84 秒 | 2.26～3.55 秒 |
| 191.051 秒首次运动恢复 | 32.73～33.07 秒 | 2.82～4.36 秒 |
| 190.5 秒缓存恢复 | 35.52 秒 | 1.99～3.08 秒 |
| 再到 191.051 秒 | 32.73 秒 | 1.92～2.94 秒 |

一次共用准备入口测量：读取 0.992 秒、准备 0.944 秒、装载 0.780 秒、恢复 3.805 秒，合计 **6.52 秒**。内存修改后准备及恢复 5.37 秒。不含文件选择、波形后台任务及 GPU 首帧。191 秒的运动采样由 730 次降到缓存后的 79 次，缓存约 67.6 KiB；定位最大帧间隔 31.8～50.3 ms。

**首次打开稳定 5 秒以内、普通定位稳定 2 秒以内、缓存定位 1 秒以内仍未全部达到。**领域和角色会话仍从初态恢复；项目读取、领域初始化、场景装配仍同步执行。

五分钟压力谱在内存构造 10000 个普通音符（含 20 Hold）、10 条三节点 Tuning、10 批 Ghost。长音/调频集中前 30 秒，后半曲为密集 Tap：准备 2.38 秒、装载 3.61 秒，150 秒定位 20.12 秒，299 秒首次 48.27 秒，重复后段约 37～38 秒。初始化最大帧间隔约 1.25 秒，重复恢复约 80～86 ms。**压力谱未达到流畅编辑目标**，剩余热点为同步初始化和大量历史输入处理；后段无活动 Hold，身体缓存帮助有限。

原始阶段计时、调用数和缓存大小见 `chart-editor-preview-second.json`、`chart-editor-preview-dense.json`。

## 验证与复现

已通过第二关上述位置、Ghost 示例及回拖的完整快照、成绩摘要、波前、活动音符和 Hold 折线对照。身体容差 0.001 像素；Spine 单精度分批允许 0.01 像素，实测不足 0.005 像素，轨道时间容差 0.1 ms。人为漏掉生侧按下后，失败 Hold 在 4.5、6.2、8.8、9.6、11 秒的逐帧播放与定位一致。

缓存命中、Tuning 修改失效、恢复原内容、场景复用、64 MiB 淘汰、取消、后台暂停和清空通过。现有写谱器测试的跨 BPM、偏移、保存、ZIP、交互和历史通过。实际图形窗口 1280×720、1440×900、1920×1080 的蒙版覆盖和显示时机通过。

BOSS 特殊路线全部组合、长时间真人编辑及 GPU 性能未穷尽验收。当前角色无 Spine 物理约束，后续引入时需重新验证历史恢复。

在 Game 使用 Godot 引擎：`godot --headless --path . --max-fps 60 --script <脚本> -- --chart-editor`。

- `tests/editor/measure_preview_restore.gd`：只读第二关；加 `--dense` 测压力谱，输出至 builds。
- `tests/editor/run_preview_restore_tests.gd`：默认 Ghost 示例；加 `--second` 固化新旧对照，之后可加 `--reuse-baseline`。领域或资源变化后重建基线。
- `tests/editor/run_preview_cache_tests.gd`：缓存、失效、复用、淘汰。
- `tests/editor/run_preview_failure_tests.gd`：失败长音对照。

Windows release 模板不支持 `--script`；脚本由工程引擎执行，发行 EXE 单独做启动检查，不把未执行的脚本当作通过。

## 发布配置回归补充

v0.1.5 初版遗漏了运行目录旧 Excel 与源码字段目录不一致的情况，导致第二关在运行目录无法预览。本次改为构建时封装参数，发布程序不消费遗留外部工作簿。

实际导出资源验证：写谱器与游戏的 49 项封装数值相同，等于各自构建时读取的开发工作簿。对写谱器 PCK 执行 `run_packaged_preview_tests.gd`，第二关 222 个基础音符、34 条 Tuning 正常载入，191.050998 秒→120 秒→191.050998 秒结果一致，返回区域命中 2 份运动缓存。显式传入遗留旧表也不影响包内预览。对真正的游戏 EXE 运行第二关临时试玩入口，完成装载并报告 ready，正常退出，日志无错误。试玩启动器的请求、轮询、错误与临时参数清理回归通过。

这组测试验证发布参数与正式加载链路，不替代有画面的完整歌曲试玩。前文首次加载和密集谱面的未达标性能项仍保留。
