# 《冥河，冥河！》干涉玩法试错历程

> 文档用途：记录干涉、共振、频率与相位相关机制的选择依据  
> 覆盖范围：Web 原型 2.0 至 3.0、前置讨论与当前 Godot 原型  
> 更新日期：2026-09-06

## 起点：两个波源必须产生第三种结果

上下两界各有一口编钟。如果两口钟只是对应两条音符轨，“生死相干”就只剩美术包装。因此早期设想增加白色目标：生波和死波单独无法处理，只有两侧共同作用才会产生白色相干结果。

最初还讨论过让玩家调整音高、频率或相位。这个方向在 2.0～2.4.1 阶段没有采用。辨认音高会限制作曲和写谱，连续调参会破坏两键操作；真实二维声场也难以稳定写谱。这一阶段遵守三条底线：输入仍是生、死两键；频率表示敲击密度；物理概念负责组织玩法和演出，不要求数值模拟真实声场。

## 版本记录

| 2.0 白色相干 | 白色音符要求双押或双 Hold，两道音波斜向汇合 | 规则清楚，但输入等同普通双押／双长按，差异主要在表现 | 放弃白色直接输入；保留双键、预判音波和白色结果 |
| 2.1 载波织相 | 按住一侧持续发波，再用另一侧连续 Tap，一节一节织出白结 | 身体动作与双押不同，但仍可用“一侧长条＋另一侧单音”直接实现，信息量反而更大 | 放弃载波相干；保留成功节点可追溯、失败不级联的经验 |
| 2.2 双源相阵 | 两键近同时或错开半拍，选择上／中／下相位；波腹攻击实体，波节吞噬咒音，并加入返魂与 Boss 封印 | 技术闭环成立，制作人实测认为规则繁琐、观察与决策负担过高，整体体验不佳 | 回退；保留“一次输入同时影响加强带和减弱带”及返魂题材灵感 |
| 2.3 相纹翻面 | 单敲翻转明暗带，双押增幅，快速交替形成疾振，停手完成相消留白 | 四套语义彼此独立，翻相、增幅和留白缺少必要性；双钟疾振的操作和反馈较好 | 只保留疾振；其余机制退出正式谱面 |
| 2.4 拍频扫界 | 生钟、死钟各自保持一种节律，节奏密度差推动中央相纹上下移动，扫过白色目标 | 概念统一度最高，双源、频率差、移动相纹和空间目标进入同一条因果链；学习成本仍偏高 | 当时主方向，后转向 3.0 |
| 2.4.1 巫律引导 | 不改 2.4 规则，增加预演、跟奏、成纹、缓冲，重做视听提示和谱面导演 | 信息层次明显改善，仍缺少真人盲测数据 | 当时先验证理解，后被调频方案替代 |
| 3.0 相纹调频 | 从双律扫界转向按住钟并连续改变频率 | Web 原型验证调频、载波与相纹关系；其判定和视觉仍属历史版本 | Godot 继续重构为独立双侧滑条 |

## 各轮实验解决了什么

### 2.0：白色相干不能只是换色双押

2.0 建立了现行玩法的基础骨架：上下分屏、生死双键、即时判定、延迟音波、普通 Tap／Hold 和程序驱动目标。它也暴露了第一个根本问题。白色相干虽然斜跨两界，但玩家做的仍是一次双押或同时长按；去掉白色特效后，玩法与普通组合没有区别。

这一轮留下两项长期有效的结论。第一，按键后必须立刻给判定和钟声，音波击破可以延迟，但因果必须可追踪。第二，白色只能是两侧关系产生的结果，不能成为第三条换色轨道。

### 2.1：改变姿势不等于产生新玩法

2.1 把白色双押改成“持一、击一”：一侧 Hold 是载波，另一侧 Tap 成为相干节点。每次成功都能生成白结，载波断开后只留下局部缺口，不会让整段失效。

它解决了结果可追溯和失败恢复，却没有解决必要性。普通音游本来就能写出一侧长按、另一侧连续单音。为这组现成组合再增加载波状态、白结、缺口和连线，会提高理解成本，却没有改变玩家的主要决策。

### 2.2：物理关系变强，操作负担也随之上升

2.2 从波源本身出发：生钟和死钟的先后顺序决定上相、中相或下相，整片场的波腹和波节随之换位。场上同时放置实体与咒音，玩家要让波腹攻击实体，让波节吞噬咒音。普通小怪还会留下魂种，后续返魂成为 Boss 封印材料。

这版第一次让一次输入改变整片场，而不是只生成一个白结。问题也很直接：玩家要记输入先后、三种相位、三条空间带、两类对象和返魂关系。技术报告证明了状态机能运行，制作人试玩则否定了它的体验。玩法需要长篇解释，操作前要先做空间判断，已经超出本项目“两键即懂”的边界。

### 2.3：把干涉拆成四个小机制，结果失去统一性

2.3 试图用更短的口令替代三相系统：单敲让明暗带换位，双敲让相场增强，快速交替织密驻波，特定窗口停手完成相消。

口令变短了，但四种规则缺少共同的操作逻辑。翻相依赖谱面预先安排答案；双敲增幅仍像普通双押；留白是一次“不要按”的休止判定，与两个波源的持续关系很弱。实测中只有双钟疾振产生了清楚的身体感和画面累积，因此疾振被保留为 Boss 高潮，其余三项撤下。

### 2.4：用两种节律的差推动相纹

2.4 改变了问题的切入点。玩家不再选择相位，也不处理额外状态，只需要让两口钟分别完成一段可见、可听的节律。例如生钟一轮敲四次，死钟敲两次。两侧的敲击密度差形成拍频，相纹按谱面预定轨迹上下扫动；玩家的准确度决定相纹是否清楚、是否足以击破白色目标。

这个方案把几项原本分散的元素接到了一起：两口编钟是两个声源；敲击密度对应频率；频率差对应拍频；拍频推动相纹；相纹处理生死之间的白色目标。玩家不需要看 Hz、辨音高或手调相位。

轨迹必须由谱面预先确定。玩家失误只改变亮度、宽度和攻击资格，不能让相纹一路漂到错误位置，否则一次 Miss 会破坏后续读谱，谱师也无法可靠摆放目标。每个周期只结算一次成绩和伤害，防止多个脉冲与目标造成连续扣罚。

### 2.4.1：机制没变，先把它教明白

2.4 首次试玩的问题集中在信息组织：多个收缩圈、比例数字和移动相纹同时出现，玩家需要临场数点。2.4.1 删除短促换比，减少白色目标，并把新节律拆成四段：系统预演一轮，玩家跟奏一轮，文字退场后独立成纹，最后留出缓冲。

两侧使用不同形态的节律节点，共享一枚游标；听觉提示使用短瞬态，不复制完整编钟长尾。教学周期保持正式判定窗，只取消第一次失败的级联惩罚。这样既能留下真实误差，也不会让玩家第一次见到新节律就失去整段体验。

## 3.0 至当前 Godot：双手调频与真实载波

3.0 将连续调频重新引入原型。Godot 当前由生、死两侧独立控制频率：按住钟持续发波，旋转摇杆操作有限圆弧滑条。已发出的波按固定速度传播，改变频率只影响之后的发射间隔；白色相纹来自两侧波带叠加，素音由合法的真实交点凝现。

计分滑条不再使用旧覆盖率或端点三级时间窗。每程在原定尾拍前进入末端 3% 即登记成功，尾拍统一结算 Perfect / Miss；往返每程独立，双侧组取最差结果且只计一次 Combo。显示与输入共用圆弧几何，当前支持朝向、位置、多条预告及短弧连续起手。

## 当前选择

普通 Tap / Hold 负责敲击与持续，双手独立调频负责相纹段落。目标输入是肩键加双摇杆，鼠标和键盘用于 PC 快速测试；场外按住仍以 3 Hz 持续发波。疾振代码保留，但当前五张测试谱均未使用。

保留的原则是：判定与表现分开；按键时确认普通音符资格，实体波接触时触发击破反馈；白色结果来自两侧关系；已发波不随新频率重排；组合判定避免一次失败重复扣罚。早期“只用两键、不允许连续调频、相纹轨迹预定”的约束已不适用于当前原型。

## 仍需验证

重点是玩家能否读懂圆弧起手、方向与折返；短弧连续段是否容易重新接入；双手不同朝向的组合是否舒适；多条预告是否清楚；真实声波、相纹和声音能否解释玩家操作。当前使用程序节拍音与占位美术，这些体验结论仍需在正式音乐、素材和真人试玩中验证。
