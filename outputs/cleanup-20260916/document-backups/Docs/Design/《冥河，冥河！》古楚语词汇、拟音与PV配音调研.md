# 《冥河，冥河！》古楚语词汇、拟音与 PV 配音调研

日期：2026-09-09  
用途：PV 旁白、角色台词、祭辞、吟唱的选词和录音准备。  
范围：以战国楚地的汉语及《楚辞》语言为中心，区分先秦用例、汉代及后世注释、现代拟音和表演设计。本版是有出处的制作选编，不是古楚语完整词典，也不是经过专家审定的楚方言发音教材。

**结论：没有古汉语专家，也能完成有依据、有辨识度的配音。应先选定一种读音方案，再把少量台词制作成固定的学习材料，让播音同学负责模仿、记忆与表演。不能仅凭“读起来很古老”，就声称恢复了战国楚人的真实口音。**

用户提供的《离骚·上下求索》可以作为具体参照。它不是单纯把普通话唱得古朴，而是对音节本身做了拟古处理。若目标就是这种陌生而有规律的听感，项目应建立与该视频方案相容的台词稿；本报告另列的白一平—沙加尔字音只用于研究对照，不能混入视频方案。

## 2. 截图中的特殊注音是什么

它主要使用**国际音标 IPA 的字母和附加符号**来写拟音。国际音标是一种记录声音的方法，不是古代楚人的文字，也不是台湾注音符号。使用 IPA 只能说明“打算发什么音”，不能证明这个音就是历史真相。

图中有些字母看起来与英文字母一样，但发音不能按英语或汉语拼音直接读。尤其 `g` 与拼音 g、`r` 与普通话 r，不是一回事。

| 符号 | 通常表示什么 | 给演员的入门提示 |
| --- | --- | --- |
| `ŋ` | 软腭鼻音 | 类似普通话 ang、eng 最后那个鼻音；图中“玉”的开头就在用它。不要在前面额外加一个元音。 |
| `ə` | 中央元音 | 舌头相对放松，近似轻读音节里的中性元音；不同于把普通话“饿”完整念一遍。 |
| `ʌ` | 次低后不圆唇元音 | 不是字母 v，也不是“啊”的统一替代写法。先用音标示范找位置。 |
| `ʔ` | 声门塞音 | 让气流在声门处短暂闭住；不是问号，也不是要多念一个字。 |
| `ɦ` | 浊声门擦音 | 带声带振动的声门摩擦；可以从轻微带气的有声起音体会，不要自动换成普通话 h。 |
| `h` | 清声门擦音 | 要区别于 `ɦ`；也要区别于上标的 `ʰ`。图中“驷”的尾部有这个字母。 |
| `ʰ` | 送气 | 例如 `kʰ` 近于拼音 k 的送气方式；这是前一个辅音的性质，不是另加一个 ha。 |
| `ˤ` | 咽化附加标记 | 图中类似上标小 `ʕ` 的符号，按通常语音记法表示咽化。不是声调或幂次；此处如何实现，还需服从作者自己的方案。 |
| `g` / `ɡ` | 浊软腭塞音 | 声带振动；普通话拼音 g 通常是清、不送气的 [k]，不等同于此音。 |
| `t` | 清、不送气齿龈塞音 | 发音方式可先借普通话拼音 d 理解；不能按拼音 t 强送气。 |
| `r` | IPA 通常表示齿龈颤音 | 不是普通话 r。历史拟音中的 r 也可能是较宽泛的流音记号，不能据此断言作者实际唱成了标准大舌颤音。 |
| 韵尾 `-k` | 音节末的软腭闭塞 | 先发元音，末尾收住；不要把它读成“克”，否则会凭空增加音节。 |
| `ː` | 长音标记，本截图未用作主要标记 | 郑张等拟音表中常见；表示时长，不是冒号或声调。 |

符号名称与标准发音部位依据[国际语音学会互动 IPA 表](https://www.internationalphoneticassociation.org/IPAcharts/IPA_charts_TI/IPA_charts_TI.html)。其中“给演员的提示”是练习说明，不是古楚口音认证。

**先学普通话之外的几个发音动作，再学固定词句，比先背完整 IPA 表更有效。**可以用[纽卡斯尔大学 IPA 口型和发音视频](https://teaching.ncl.ac.uk/ipa/chart.html)练单个音。该站不少辅音放在元音之间示范，跟练时要辨认目标辅音，不要把示范前后的元音都加进台词。

### 2.1 截图中的逐字对照

下表转录约 00:45 画面的字音。将画面上咽化标记统一排作 `ˤ`，`g` 保留常见拉丁字形；这是字幕转录与排版统一，不是重新拟音。因没有作者的可复制音标稿，精细字符仍以原字幕和作者说明为准。

| 原字 | 现代汉语读法 | 视频字幕拟音 | 在这句中的意思 |
| --- | --- | --- | --- |
| 驷 | sì | `sih` | 这里作驾驭、以四龙驾车理解 |
| 玉 | yù | `ŋuk` | 玉、美玉般的 |
| 虬 | qiú | `grou` | 龙类名称 |
| 以 | yǐ | `ləʔ` | 用以、而等连接作用，依句法解释 |
| 乘 | chéng | `ɦləŋ` | 乘坐、驾乘 |
| 鹥 | yì | `ʔˤi` | 这里指凤类神鸟 |
| 兮 | xī | `ɦˤe` | 语气与节奏成分 |
| 溘 | kè | `kʰˤʌk` | 忽然、迅疾之意 |
| 埃 | āi | `ʔˤə` | 尘埃；“埃风”连文的解释有讨论 |
| 风 | fēng | `kouŋ` | 风 |
| 余 | yú | `lʌ` | 我 |
| 上 | shàng | `dʌŋʔ` | 向上 |
| 征 | zhēng | `teŋ` | 行进、远行 |

这两句大意可读作：驾着玉龙、乘着神鸟，迅疾乘风向上远行。这里采用便于理解的整句意译，不把存在解释分歧的词组硬拆成机械替换表。

以“玉 `ŋuk`”为例，只有一个音节：**鼻音起头 → 元音 u → k 收尾**。读成“嗯—乌—克”就是三个音节，已经改变了字幕所写的结构。“以 `ləʔ`”也是一个音节，最后闭住声门，不再补一个“呃”。

特别注意两处：

- 视频把“风”写成 `kouŋ`，不是把“风”的普通话声母随意读错。画面解说把它放在楚方言唇音与牙喉音交替的讨论中。但这是有条件、有词例的处理，不能推广成所有 f 都换 k。
- 视频的“上”为 `dʌŋʔ`，不能因为今天 shàng 是去声，就自行改成某个带 h 的形式。现代声调、古字音和词在句中的用法，需要分别核对。

### 2.2 怎样把这首歌变成你们的配音参考

可参考的是固定音节、辅音衔接和词句陌生感。曲调、节拍、音区、旋律中的拖腔属于这首现代音乐作品；不能拿它们反推战国楚人的日常语调或祭歌旋律。

可以从视频中找与你们台词相同的词，建立带时间点的内部学习索引。同字不同义、不同读法仍需分开。例如“乐”“长”“重”“与”“女”不能只建一个条目。

若想把视频方案延伸到未出现的新句子，最有帮助的材料是：作者的完整 IPA 歌词、采用的书目页码、相对郑张原表的改动，以及是否能给出几句慢速示范。可以向作者询问这些材料；本次没有代为联系作者。

## 3. “古楚语”必须先限定到哪个对象

| 常被混称的对象 | 本次如何处理 |
| --- | --- |
| 战国楚地使用的汉语 | 本项目拟古配音的主要历史参照；地域、年代、阶层仍有差别。 |
| 《楚辞》的传世文学语言 | 最实用的选句来源；兼有共同语、楚地词语与文学表达，不是楚人日常对话录音。 |
| 汉代《方言》及后世注家记录的楚语 | 重要证据，但记录时代与解释时代可能晚于战国，不能全部无条件前推。 |
| 楚国境内其他语言及非汉语成分 | 应按具体材料研究。楚国语言接触很复杂，不宜把古越语、现代少数民族语言直接等同于楚语。 |
| 现代湖南、湖北方言及其他南方方言 | 可以借助其中的声音训练演员，也可作为创作素材；不能仅凭地域或某个保留特征，把整套现代方言当作古楚语。 |
| 现代古音演唱、吟诵、拟古配音 | 可作声音设计参考；历史字音、传承读法、音乐创作和合成器实现要分别看。 |

学术上可以结合押韵、声符、通假、出土楚简、后世音韵资料及比较材料研究楚方音，但从这些证据到“某年某地一个人怎样把整句话说出来”，仍有距离。[古屋昭弘《上古音研究と戦国楚簡の形声文字》](https://www.jstage.jst.go.jp/article/chuugokugogaku/2010/257/2010_4/_article/-char/ja)讨论了此类材料与方法。

《周秦两汉楚方言词研究》的成果介绍给出了跨地域、跨时代的数百词规模，足见材料并非只有“於菟”几个词。但那不是已经录好音的战国口语词典。本次只核实了公开成果介绍，没有阅读全文，不能把其中的全部音系观点说成学界一致意见。[国家社科基金项目成果介绍](https://www.nopss.gov.cn/n1/2022/0322/c373410-32380658.html)。

还有一个常见误区：《越人歌》的越语记音与楚语译辞不能混为一谈。《说苑》叙事本身就区分了越歌与为楚人解释的译辞。喜欢它可以用作文学参照，不能把网上“古越语复原”直接移植成古楚语。[《越人歌·说苑版》所录原典](https://zh.wikisource.org/zh/越人歌_(說苑版))。

## 4. 楚地特色词汇选编：现代汉语对照

**本表的拼音是今天读古文时使用的读音或明确标出的旧读，不是战国发音。**古音若没有逐项核对，这里不填。方言归属通常只针对特定义项：“古书说楚地这样用”不等于“此字只有楚人能用”。

来源简称：下文“方言”为扬雄《方言》，可查[《扬子云集》卷三收录本](https://zh.wikisource.org/zh-hans/揚子雲集_(四庫全書本)/卷3)；“补注”为洪兴祖《楚辞补注》所收王逸注及补说，分见[《离骚》注释](https://www.shidianguji.com/zh/book/HY1096/chapter/1kiiydf2zbyug)、[《九歌》补注](https://zh.wikisource.org/zh-hans/楚詞補注_(四庫全書本)/卷02)、[《招魂》补注](https://zh.wikisource.org/zh-hans/楚詞補注_(四庫全書本)/卷09)。电子本有异体字、讹字与自动标点问题，正式入稿时要核定选句底本。

### 4.1 巫祭、呼告与人物情绪

| 词 | 今读或旧读提示 | 对应的现代意思 | 文献证据与使用边界 |
| --- | --- | --- | --- |
| 羌 | qiāng | 发语、带出感叹或转折语势；可不译 | 《离骚》注释明确作楚人发语词。此处不指羌族，也不是随处可加的“楚语前缀”。 |
| 蹇 | jiǎn | 发语、语气成分；可不译 | 《九歌·云中君》《湘君》及注；与“跛足、艰难”的实词义区分。 |
| 些 | suò | 句末呼告、感叹、劝止等语气 | 《招魂》高度集中的句尾形式；不能读成“一些”的 xiē。此为现代辞书读法，不代表古音已经确定。 |
| 灵／灵子 | líng／líng zǐ | 在相应祭祀语境中指巫者 | 《云中君》王逸注明确以灵子称巫。其他句子的“灵”也可能指神或神灵，不可一律换成“巫师”。 |
| 傺 | chì | 停住、留住 | 《方言》卷七标南楚；《离骚》注以“住”解释。 |
| 侘傺 | chà chì | 失意、惆怅而停立的状态 | 《离骚》等用例及王逸注。适合心理描写，但生僻程度较高。 |
| 咍 | hāi | 嘲笑、相笑 | 《九章·惜诵》王逸注标楚人用语。可用于讥笑叙述，不等于所有笑声。 |

| 篿 | zhuān，占卜义 | 结草、折竹一类占卜方式 | 《离骚》“筳篿”王逸注；不能把圆竹器义的 tuán 读法照搬进来。 |

| 邅 | 今读 zhān；古注有异读 | 转、转道 | 《离骚》《湘君》及注。不是简单等于所有“走”。 |
| 翥 | zhù | 举起、向上腾举 | 《方言》卷十标楚；与鸟飞相关时可用于腾飞意象。 |

| 穀 | 哺乳义旧读 gòu；通行字书也有归入 gǔ 的处理 | 哺乳、喂乳 | 同一《左传》记载，与斗穀於菟之名相连。不要当作粮食“谷物”；核对[该字多义与旧读](https://ctext.org/dictionary.pl?char=穀&if=en&remap=gb)。 |

对 PV 最有用的不是把这些词都塞进一句话，而是按镜头选择少数有意义的词。例如涉水场景可以用“潭”，祭辞可用“灵”，衣物漂失可用“褋”。“於菟”虽然证据明确，若没有虎的画面或相关叙事，就不必为了展示考据而硬加。

## 6. 古音能查到什么程度：一个可核对的对照表

为了显示“现代读音”与“上古拟音”究竟相差在哪里，以下列出白一平—沙加尔 2014 版 1.1 原表的选项。**它们是通用上古汉语研究中的构拟，不是上一视频的楚音，也不是项目默认录音稿。**

音形来源：[作者公开的拟音表 PDF](https://sites.lsa.umich.edu/ocbaxtersagart/wp-content/uploads/sites/1415/2025/03/BaxterSagartOCbyMandarinMC2014-09-20.pdf)。页码为 PDF 阅读器页码；印刷页码通常少两页。本次逐项检查了表中文字，并对“魂”“来”“兮”所在页另做了图像核对。PDF 文本提取会把 `ə` 重复为两个字符，表中已按可见排印规范统一。

| 字 | 今读 | 原表拟音或所示演变 | PDF 页 |
| --- | --- | --- | --- |
| 魂 | hún | `*[m.]qʷˤə[n]` | 48 |
| 魄 | pò | `*pʰˤrak` | 86 |
| 兮 | xī | `*gˤe` | 119 |
| 归 | guī | `*[k]ʷəj` | 40 |
| 来，来临义 | lái | `*mə.rˤək (> *rˤə)` | 66 |
| 钟，鐘 | zhōng | `*toŋ` | 157 |
| 死 | sǐ | `*sijʔ` | 106 |
| 生，出生／生活义 | shēng | `*sreŋ`，原表另列 `*s.reŋ` 的可能 | 101 |
| 灵 | líng | `*[r]ˤeŋ`，原表释义为 supernatural | 71 |
| 冥 | míng | `*mˤeŋ` | 79 |
| 江 | jiāng | `*kˤroŋ` | 54 |
| 河 | hé | `*[C.g]ˤaj` | 42 |
| 水 | shuǐ | `*s.turʔ`，附东方言 `*-r > *-j` 的说明 | 105 |
| 月 | yuè | `*[ŋ]ʷat` | 147 |
| 日 | rì | `*C.nik` | 95 |

这里的 `*` 表示构拟；方括号表示成分的具体身份有不确定性，圆括号表示有无不确定，`C` 表示未具体确定的辅音；它们不是要念出的字母。`>` 表示音变关系。原表同时有中古音 MC 列和上古音 OC 列，查资料时要选对列。更详细的记号定义见该 PDF 前两页。

例如“兮”，视频写 `ɦˤe`，这张表写 `*gˤe`：两者有可比较之处，但开头的辅音已经不同。不能今天从视频学一个字，明天从白沙表拣另一个字，再把拼起来的句子称为“同一套战国楚语”。

“来”的演变式、“水”的方言附注、带 `C` 的词，都说明**查到一个符号串，不等于拿到唯一可直接表演的声音**。要把拟音变成录音，必须另写“本项目选哪一形、如何读”的实现说明。

不能给整段战国楚辞机械套入普通话四声；也不能把“所有古汉语都绝对无声调”当作统一前提。不同年代、不同构拟对于韵尾、发声态与声调发展的处理有分歧。唱段里的音高尤其首先受现代旋律约束。

## 7. 没有专家，如何完成配音

### 7.1 按声音用途选择工作量

| 用途 | 可执行方式 | 对团队的要求 |
| --- | --- | --- |
| 解释世界观的长旁白 | 古典词句或现代文案，以明确的今音朗读 | 播音表演、断句、古文多音字校对 |
| 关键角色的一两句短台词 | 固定稿件，选择一套拟音后逐音节学习 | 要有可追溯读音稿；必要时做明确的表演简化 |
| 呼告、祭辞、反复吟唱 | 选择二至四个短句，做同文重复、独唱与回应 | 最适合用有限训练取得稳定的拟古效果 |
| 全 PV 都采用作者式楚音 | 可以作为制作目标，但需先试录再定规模 | 新句逐字取证与示范的工作量明显更大，单靠一首参考歌不够 |

结合你们目前的资源，建议把最鲜明的拟古声音放在**重复出现的仪式句和少量关键话语**。观众依靠字幕理解它们，演员也可以把有限音节练熟。信息密集的解释是否也使用拟古音，可由第一轮试录的效果决定。

这不意味着播音同学必须改学语言学。演员要解决的是“这句在此版本怎样稳定发出来、说给谁听、为什么要说”；资料整理者要负责“为什么选择这个音”。如果需要增加一个协作者，优先考虑能制作明确示范的古音爱好者、语音学学习者或方言／台词指导，不必把所有希望寄托于请到一位教授。

### 7.2 最小分工

1. **文案与读音负责人**：可以由主策划担任，维护一份确定版本的台词表，核对古文、字义和读音出处。
2. **演员**：学习固定稿，录制不同情绪和力度，报告发不稳、记不住的位置。
3. **音乐／声音负责人**：安排音高、节拍、换气和人声层次，保证后期不把关键收尾切掉。

不要求三个人都懂古音，也不要求三项职能一定由三个人担任。但不能让三个人各自从网上选一套“觉得像”的读音。

### 7.3 实际流程

**第一步：先锁定文字和现代意思。**

列清楚说话者、听话者、原文、现代意思、出处或“游戏原创”、镜头时长。先检查多音字和断句，再开始拟音。不要把现代汉语台词逐字换成生僻字就称古楚语。

你们立项书中的“非钟生余音，乃明日呼我。”可作为游戏原创台词保留原文，不需要为了古化而强行改写。它的叙事意义来自项目设定；即便随后加了上古拟音，也不会因此变成出土文献中的古代原话。

**第二步：固定一套读音方案。**

如果采用视频作者方案，先抽取确有字幕依据的词句；新台词的未知字单列出来。无法解决的词可以先保留今音试读、换成已核对的古文短句，或暂不进入正式拟音录制。不要用另一套拟音悄悄补洞。

**第三步：给演员“音标＋口型动作＋慢速示范＋正常语速示范”。**

音标定义可以从大学和国际语音学会资源学习；完整句子的慢速示范应由本项目指定的一个人录制并固定版本。该人不是专家也可以，但要把自己的实现选择说清楚。一个难音若决定简化，保留原拟音列，在“实际录音读法”列明确记录，随后重复处保持一致。

AI 语音、虚拟歌手可以辅助预演，但只有在输入方式与输出音节经过人工确认后，才适合当演员模仿对象。给普通话 TTS 输入一串 IPA，不保证它会正确发音；输出听着陌生也不能当作证据。

**第四步：先做短试录，再扩展。**

先选一小段，分别录平直念读、角色说话、简短吟唱三种版本。此时只做轻量整理，先听辅音起头、元音和收尾是否稳定。团队确认演员能重复、情绪成立、字幕能跟上，再录全稿。

可先按三至五个工作日安排一轮小样：准备稿件一天、分音节学习一天、试录和修订一天，余下用于正式录音及混音。此为制作估算；句长、演员经验和陌生音数量会改变所需时间，不能保证一天能学会整套楚音。

**第五步：用音乐创造仪式结构。**

这是现代声音设计，可以大胆做：领唱一句、群声回应一句；生者与死者唱同一文本；前半段错开起音，后半段逐渐重合；让人声尾音接入钟的余响。它们与你们的两界与声波主题相容，无须额外发明一套语法。

不要把“古楚”规定成统一的低沉吼叫或气声。远距离召回、近身安抚、郑重告知、疑惧确认，都能产生不同的声音。先让演员知道行动目的，再决定音色。

若音节有 `-k`、`-t`、`-p` 等收尾，需要拖长时可将时长放在前面的元音，最后完成收尾。具体音乐处理是项目选择，不能冒称原始楚歌的唱法。

**第六步：保留干声，做有限核查。**

视频制作可统一录制 48 kHz、24-bit WAV 干声，按句和 take 区分；另交成片处理版。不给原始录音直接烘焙重混响，方便修改字音和节拍。听审时至少检查：同词多次是否一致、闭塞收尾是否误加元音、是否漏字、音乐是否遮住关键信息，以及去掉“古楚语”标签后表演本身是否仍成立。这些是制作检查，不能取代历史语音鉴定。

## 8. 一张演员可以照着练的示例卡

这张卡练的是**用户视频已出现的读法**，不是我新拟出来的古楚语。选“玉”和“以”是因为它们能训练两类关键收尾，练习时没有必要立刻唱完整首歌。

| 项目 | 内容 |
| --- | --- |
| 参考版本 | NBluecat《离骚·上下求索》，2024-02-09，约 00:45 字幕 |
| 文字 | 玉；以 |
| 现代读法与意义 | yù，美玉；yǐ，连接、凭借等，依原句 |
| 字幕目标 | `ŋuk`；`ləʔ` |
| 玉的动作 | 找到 ang 末尾的鼻音位置，将它放到音节开头；接 u；舌后部闭住作 k 收尾。全程一个音节。 |
| 以的动作 | l 起头，接放松的中央元音 ə；声门轻闭作 ʔ 收尾。全程一个音节。 |
| 先录什么 | 单词慢读各三次，再放回原来的短语；每次之间留空。 |
| 演员最容易错在哪里 | 玉读成三段“嗯乌克”；以的末尾补出“呃”；为了古老感用力挤嗓。 |
| 判断通过的方式 | 同一个演员多次重复时结构一致，并能从平读转到角色语气。 |
| 未解决的事 | 这张练习卡不鉴定视频的历史拟音是否正确，也未对其合成演唱逐音验证。 |

正式台词表建议只保留以下列，不用做复杂系统：

`编号｜说话者／对象｜台词原文｜现代意思｜文本出处｜读音方案与依据｜IPA｜实际表演读法／示范时间点｜节拍与换气｜采用的 take`

演员手上可以是经过减负的版本，但负责资料的人应保留完整 IPA 和出处。汉字谐音只适合作为临时记忆提示，不能作为最终唯一读音稿。

| 入不言兮出不辞，乘回风兮载云旗。 | rù bù yán xī chū bù cí，chéng huí fēng xī zài yún qí | 来去不发一言，乘回旋的风，载着云旗。 | 《九歌·少司命》；神秘人物的出现和离去。 |
| 成礼兮会鼓。 | chéng lǐ xī huì gǔ | 礼仪完成，鼓声会合。 | 《九歌·礼魂》首句；是节选，不能把截取后的句子当作整首原文。 |
| 身既死兮神以灵，魂魄毅兮为鬼雄。 | shēn jì sǐ xī shén yǐ líng，hún pò yì xī wéi guǐ xióng | 身虽已死，精神仍显灵；魂魄刚毅，为鬼中英雄。 | 《九歌·国殇》；原本有阵亡将士语境，不是泛说所有亡魂。 |

出处：[《招魂》原文](https://zh.wikisource.org/zh-hans/楚辭/招魂)、[《九歌》原文](https://zh.wikisource.org/zh-hans/九歌)。以上现代释义为本报告所作简译。

《大招》反复用“只”作句尾语词，与《招魂》“些”的形式不同。这可以作为另一种文本选择，但不宜为了古怪把“兮、些、只、羌”全堆在同一段里。[《大招》原文](https://zh.wikisource.org/zh-hans/楚辭/大招)。

“魂兮归来”与本作“从哪一边归来”的主题很契合。两界用同一句呼告，只改变声音的位置、时间和说话对象，就能产生叙事区别。这是演出建议，尚不是对 PV 文案或音乐的定稿。
