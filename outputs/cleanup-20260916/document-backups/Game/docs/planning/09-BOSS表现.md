# BOSS 表现

正式关卡与 `tools/boss_animation/review.tscn` 素材审看共用完整表现实现。修改工作簿后重新装载关卡或审看场景。关卡对象及绑定可以覆盖战斗与发射默认值。

| 字段 | 默认 | 范围 | 步长 | 用途 |
| --- | ---: | --- | ---: | --- |
| `boss/glow_strength` | 1.0 | 0～2 | 0.1 | 光波、喷火、眼光、羊头裂光与白场亮度。觉醒时两侧眼睛变白，额眼保留虹膜。手部不整体提亮。 |
| `boss/effect_scale` | 1.0 | 0.5～1.5 | 0.1 | 光波、火焰、羊头光束及骨片扩散范围，发射根部保持绑定。 |
| `boss/fragment_multiplier` | 1.0 | 0.25～2 | 0.25 | 实例创建时决定附属碎屑数量。羊头六片额眼表层与34块骨片固定。 |
| `boss/health_ratio` | 0.8 | 0.05～2 | 0.05 | 最大血量占所属音符理论总伤害的比例。Perfect 伤害 1，Good 0.5，PASS／Miss 为 0。 |
| `boss/flight_speed` | 600 | 100～3000 | 10 | 设计像素／秒，按曲线弧长反推提前时间，不改变判定拍点。 |
| `boss/spread_deg` | 30 | 0～60 | 1 | 对应侧散射半角，单位度；稳定 ID 决定每枚音符的方向。 |

动作时序和骨骼编排保存在派生素材中。外观倍率不写入玩法判定哈希；BOSS 战斗配置作为 Replay 可选扩展保存，不改变原判定摘要。

Tap 结算一次伤害；Hold 头尾各一次、持续每拍一次，不足一拍按时长折算。调频每拍固定 48 个时间切片统计有效覆盖，按现有调频完成度阈值分级。伤害以千分之一单位整数累计，不随帧率变化。

半血触发配置好的转阶段。零血先进入破防，继续发射；最后一波的判定及物理收尾结束后死亡。未击败则撤退，不额外判失败。音乐结束后死亡与曲后演出并行，二者都结束再结算。

羊头一阶段使用3秒 `phase_break`，结束后进入真眼形态常态。二阶段死亡7秒；白场在4.80～5.15秒渐满，5.15～5.65秒保持，5.65～6.65秒退去。双侧白场取最大强度，审看控件位于白场上方。默认倍率1时达到纯白。

制作规则：BOSS 静息映射循环播放。单一已配置或已绑定 BOSS 自动关联当前难度未分配的 BOSS 音符；显式绑定优先，多 BOSS 需手动指定归属。自动关联为派生结果，不改写谱面或原绑定。
