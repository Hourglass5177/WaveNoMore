# 分界线表现参数

工作簿页签：**07 分界线表现**。修改黄色 B 列当前值，保存并重新装载关卡或预览。对象名 `boundary`，不进入玩法规则或 Replay 哈希。

| 字段 | 默认 | 单位 | 含义 |
| --- | ---: | --- | --- |
| `enabled` | 1 | 开关 | 关闭显示原始静态分界线 |
| `vortex_inner_radius_px` | 88 | 设计 px | 中央留白基准；向外移动弧面 |
| `vortex_width_px` | 112 | 设计 px | 向外缘增加厚度，入口下缘保持上行 |
| `vortex_foam_strength` | 0.65 | 比例 | 沿卷流前进的骨白细水纹强度 |
| `vortex_flow_speed_px_sec` | 96 | 设计 px/s | 中央水纹沿曲线连续前进的速度 |
| `vortex_beat_push_px` | 1.25 | 设计 px/拍 | 每拍前 0.4 拍柔和增加的路程；0 关闭提速 |
| `flow_enabled` | 1 | 开关 | 基底水流开关，中央和小浪独立运行 |
| `flow_speed_px_sec` | 60 | 设计 px/s | 基底原纹流速，不随 BPM 加速 |
| `flow_strength` | 0.80 | 比例 | 基底原纹流动颜色的混合强度 |
| `streak_strength` | 0.24 | 比例 | 基底细水线强度；0 只关闭该细纹 |

尺寸以 1920×1080 为基准。中央两股厚浪常驻，原纹和细沫持续顺时针流动，末端逐渐消退。调整厚度不会向下挤出浪根。小浪保留每拍产生、三拍消退和约 140 px 前进。

厚度定义水坡的几何基准，上侧另有 40% 空间供带透明缺口的浪唇翻出。浪唇以 1.06 倍基础速度推进，细水为 1.12 倍；原画附件的分叉和空腔决定每一时刻的外轮廓。

中央基础流速使用绝对歌曲秒数，额外推进使用 TempoMap 和连续累计拍位；变 BPM 和换拍号不重置水纹位置。拍点回应始终向前，不积累形变。基底沿用原有双阶段 2 秒流动，透明轮廓不变。

旧中央参数 `bar_interval`、`vortex_outer_radius_px`、`vortex_sweep_degrees` 停用，工作簿灰色行保留原当前值。更早的拍落与呼吸参数记录继续保留。此次仅将浪身宽度当前值更新为 112，新增流速与每拍推进采用上述默认；其他人工当前值不重置。
